## 2. 변경 내용과 **회귀가 아닌 근거**

**② 본문 매칭을 공백 허용으로** — 공용 헬퍼 하나를 만들어 **두 매칭 지점**에 함께 적용:
  · `_basic_items` 기본항 `NN. <용도지역> : NN퍼센트` (현 `re.escape(zone)`)
  · `_iter_zone_fragments` 앵커 `alt` (현 `re.escape(z)`)

★**문서를 정규화하지 않는다.** 내가 실험에서 쓴 `re.sub`(문서 전체 공백 제거)는
`evidence_span`·`context` 발췌의 **문자 오프셋을 어긋나게** 해 증거 품질을 떨어뜨린다.
**needle(패턴) 쪽만** 공백 허용으로 만든다.

*회귀 아님*: `\s*` 는 **공백만** 매칭하므로 기존 무공백 표기는 그대로 매칭된다(상위집합).
기존 자연녹지 결과(bcr 20·far 100)가 불변임을 락으로 고정한다.

**⑤ DRF 200-실패를 조례 경로에서도 감지** — `moleg_drf_envelope` 에 **XML 형제**를 추가.
현 검증기는 `isinstance(payload, dict)` 라 **JSON 전용**이고 조례는 `type=XML` 이라 무방비였다.
형제 2곳(`regulation_monitor`·`gosi_search_service`)은 이미 검증하는데 **조례만 빠져 있다**.

*회귀 아님*: 실패 감지만 추가하고 성공 경로의 파싱은 건드리지 않는다.

## 3. ★검증하지 못한 것

- **오산 외 지자체에서 이 공백 표기가 얼마나 퍼져 있는지 미측정.** 표본 1건(오산)이다.
  다른 지자체가 또 다른 표기변형을 쓸 수 있다(선례: ‘안에서의’·분수형).
- **`far_eff` 가 실제로 230 으로 바뀌는지 라이브 확인은 배포 후에만 가능**하다.
  로컬 파서 단위로는 230 을 확인했다.
- **성장관리권역 조건부 값(제50조 30%)이 이 부지의 실제 적용값인지** 판단하지 않았다 —
  2026-08-19 문서가 남긴 미결이고 **이 PR 범위 밖**이다.
- **`conditional_limits` 의 우선순위 모델**은 손대지 않는다(같은 문서의 미결).
- 조례 원문의 **별표(別表)** 경로는 태우지 않았다.
