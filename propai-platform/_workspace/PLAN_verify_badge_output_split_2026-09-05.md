## 2. 변경 내용과 회귀가 아닌 근거

**P0 — 못 재면 판정하지 않는다.** `output` 을 특정할 수 없으면 **검증을 호출하지 않고**,
점수 대신 *"AI 서술이 없어 판정하지 않음"* 을 표시한다. 지금은 자기대조 결과를
**「근거 N%」**로 보여 주는데, 그 수는 **구조적으로 공허**하다(감정평가 화면에서).

**P1 — 목록형을 없앤다.** 배지에 **명시적 `output` prop** 을 추가해 **생산자가 선언**하게 하고,
`desk_appraisal` 은 `apprNarr` 를 넘긴다. 키 이름 추측(목록)은 **레거시 폴백**으로만 남는다.

**P2 — ★이름이 곧 단정이다(sid=e739d2a9 제보).** 「근거 N%」는 **무엇의 비율인지 말하지 않는다.**
사용자는 그것을 «AI 서술의 근거율»로 읽는데, 실제로는 `grounded_score`(원본 근거 충실도)이고
분리가 안 될 때는 **아무것도 아니다**. 라벨을 **무엇을 잰 것인지 말하는 형태**로 바꾼다.
★그 세션이 같은 날 `MEDIA_ERRORS` 판정어에서 데인 자리이고, 내 메모리의 «자기 상수를 단언하는
락»(`limit == QUOTA_LIMIT_UNKNOWN` 이라 그 상수를 «무제한» 으로 바꿔도 통과)과 **같은 뿌리**다.

**회귀가 아닌 근거**: `output` 을 주지 않는 기존 마운트는 **폴백이 그대로 동작**한다(멱등).
분리가 되던 타입은 값이 변하지 않고, **분리가 안 되던 타입만** 거짓 점수 대신 정직한 표시로 바뀐다.
피드백 위젯은 전제 9에 의해 **무영향**이다.

## 3. ★검증하지 못한 것

1. **다른 마운트 5곳이 실제로 `hasSplit=false` 인지** — 응답 구조를 각각 재지 않았다(`desk_appraisal` 만 ast 로 확증). **미측정**.
2. **`apprNarr` 를 output 으로 넘겼을 때 검증 품질이 실제로 나아지는지** — LLM 판정이라 라이브 호출이 필요하고, 그것은 **비용**이다. 이번엔 **배선까지만** 하고 품질은 재지 않는다.
3. 기존에 쌓인 `recurring_verify_error` 인사이트는 **줄지 않는다**(과거 행은 안 고친다).
4. `esg`·`market` 처럼 LLM 키가 있는 타입에서 **폴백이 옳게 갈랐는지** 미확인.

## 4. 되돌리기 경로

`output` prop 은 **선택적**이고 P0 게이트는 한 조건문이다. 되돌리면 즉시 원상복구되며
데이터 마이그레이션이 없다.
