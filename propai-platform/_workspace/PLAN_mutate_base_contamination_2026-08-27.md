## 2. 변경 내용과 회귀가 아닌 근거

`_resolve_base(base)` 를 넣어 base 를 **HEAD 와의 공통 조상까지 낮춘다.** 두-점은 유지한다.

- 회귀가 아닌 근거 ①: 조상 ref(`HEAD~1`·`HEAD~5`)에는 merge-base 가 **항등**이라 기존 용법이 그대로다.
- 회귀가 아닌 근거 ②: 워킹트리 미커밋 변경은 여전히 대상이다(락으로 단언 — 3-dot 과잉교정 방지).
- 회귀가 아닌 근거 ③: 실패 시 base 를 **그대로 두고** 경고한다 — 임의로 갈아치우지 않는다.
- 부수: 해석된 base sha 를 실행 출력에 찍는다. **이번 오염이 조용했던 근본이 "증거에 base 가
  안 적힌다" 였다** — 생존 N건만 인용되고 무엇을 대상으로 쟀는지는 인용되지 않았다.

★근본이 **몰라서**가 아니었다: `--only` 주석(`:299~301`)이 *"멀티세션 저장소라 **남의 변경까지
diff 에 들어온다**"* 라고 **이미 적고 있다.** 알면서 처방을 **사람이 손으로 주는 목록형
필터**로 둔 것이다 — 저장소 지침의 「목록은 곧 상한이 된다 — 수집은 파생형으로」 그 자체다.
그래서 기본값을 고치고 `--only` 는 보조로 남긴다.

## 3. ★검증하지 못한 것

- **다른 세션들의 기존 변이 증거가 실제로 얼마나 오염됐는지는 미측정이다.** 오염 *가능성*은
  세 세션이 각각 확증했지만(10→0 · 26→21 · 7→5), **과거에 인용된 "생존 N건" 들을 소급
  재측정하지는 않았다.** 그 재측정은 각 브랜치에서 따로 돌려야 한다.
- **untracked 새 파일은 여전히 변이 대상 0건이다**(`git diff` 가 안 본다). 고치지 않았고,
  `xfail(strict=True)` 로 초록 안에 드러내 두었다 — 커밋 메시지에만 적으면 안 드러난다.
- CI 전수 회귀는 이 PR 에서 **미실행**(로컬은 관련 19건 통과). CI 결과로 확인해야 한다.

## 4. 되돌리기 경로

`_resolve_base` **호출부는 한 곳**이다 — `main()` 의 `base = _resolve_base(args.base)`.
그 한 줄을 `base = args.base` 로 바꾸면 즉시 원복된다.
(**두 곳인 것은 호출부가 아니라 *소비처*** — `_changed_files(base)` 와 `_added_lines(base, f)`.
초판에 이 둘을 "호출 두 곳"이라 잘못 적었다. 독립 리뷰가 적발.)
락 파일 하나를 지우면 잠금도 함께 풀린다(둘은 같은 커밋에 있다).

### ★★독립 리뷰가 내 "9종 전부 CAUGHT" 선언을 무너뜨렸다

초판에서 나는 **손으로 고른 9종**이 전부 CAUGHT 라고 선언했다. 독립 리뷰(반증 임무)가
**내가 만들지 않은 3종**을 만들었고 셋 다 SURVIVED 였다. 근본은 하나다:

★**내 픽스처에서 `merge-base` == `HEAD~1` == 루트커밋이 전부 같은 커밋이었다.**
분기점이 곧 저장소 루트였고 `mine` 에 커밋이 하나뿐이라, **base 를 merge-base 보다 더 낮게
해석하는 오구현이 정답과 구별되지 않았다.** 실저장소에서 그 변이(N8)가 뜻하는 것:

    올바른 merge-base = 5a79f510f  →  대상 파일     4 개
    루트커밋 해석      = acb0e41f1  →  대상 파일 3,989 개

즉 **락 12건이 전부 초록인 채 대상 집합이 1,000배가 된다.**

★구조적 원인: 하한(내 커밋·미커밋이 **남는가**)은 파생형으로 걸었는데, **상한**(남의 것이
**빠지는가**)은 `assert "shared_module.py" not in names` 라는 **목록형 단일 지점**뿐이었다.
그 한 지점은 *"base 를 안 낮춤"* 만 탐지하고 *"너무 낮춤"* 은 **원리적으로 탐지 불가**다.
**§D19(경계는 양방향) · §수집·판정(목록은 곧 상한이 된다)에 내가 정면으로 걸렸다** —
이 PR 이 스스로 인용한 원칙을 이 PR 의 락에서 어긴 형태(§D16)다.

교정: 픽스처에 **분기점보다 앞선 커밋**(`A0 → A1` 의 `ancient.py`)을 넣어 상한 축을 갈랐다.
그 파일이 대상에 **없어야 한다**를 함수 단위·배선 단위 **양쪽**에서 단언한다.

★두 번째 적발(MEDIUM): 배선 락 ②의 `assert "keep_me" not in out` 이 **공허한 참**이었다.
probe 를 `assert False` 로 둬서 도구가 **기준선 검사에서 멈추고** 변이 라벨을 한 줄도 안 찍었다
— `keep_me` 가 나타날 수 있는 유일한 자리가 그 라벨이다. 결함을 완전히 되살린 상태에서도
`grep -c keep_me` = **0** 이었다(리뷰어 실측). M2 를 실제로 잡은 건 바로 위의 **건수 대조**였다.
교정: probe 를 통과시켜 변이 루프를 실제로 돌리고, **루프가 돌았는지**를 먼저 단언한다.

★그 밖에 리뷰가 잡은 것 3건(전부 반영): `--only` 주석의 근거가 **현재형 거짓**으로 남음 ·
