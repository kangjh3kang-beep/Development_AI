# 시세보정계수의 「현실화율」이 **계수를 뒤집어 만든 숫자**였다

**작성** 2026-09-07 · sid=7d6880dd · 브랜치 `fix/market-multiplier-fabricated-rationale` · base `63a7e126c`(라이브)

## 0. 옵시디언 조회 결과 — ★조회 **실패**(참조했다고 쓰지 않는다)

볼트 `/mnt/d/옵시디언기록/나의-모든-기록-최적화본` **접근 불가**. 원인을 단정하지 않고 재봤다:

| 관측 | 값 |
|---|---|
| `mount \| grep ' /mnt/d '` | 마운트는 **살아 있다** — `D: on /mnt/d type 9p` |
| `ls /mnt/d` | `No such device`(ENODEV) |
| 대조군 `ls /mnt/c` | **정상** ⇒ 9p 층 전체가 죽은 것이 아니다 |

처방은 재마운트가 아니라 Windows 측 `wsl --shutdown`(세션 메모리 `feedback_a_live_mount_can_still_be_dead.md`).
WSL 안에서는 자기 세션을 죽이지 않고 실행할 수 없다.

★따라서 **이 계획서는 볼트 근거를 갖지 않는다.** 인계서가 인용한 볼트 4개 문서는 전 세션(sid=d67f8fff)의
측정이고 **내 관측이 아니다**(§증거 규율 7 — 라벨 미승계). 대신 **저장소 안 근거로 대체**했고, 그 대체
근거가 아래 §1 의 네 번째 행이다 — 저장소가 **자기 언어로 이미 이 금지를 적어 두고 있었다.**

## 2. 변경 내용과 그것이 회귀가 아닌 근거

**계수 값은 건드리지 않는다.** 진짜 현실화율을 잴 데이터원(표준지공시지가 대 실거래)이 저장소에 없다
(인계서 W10 과 동일 판정). 근거 없이 값을 바꾸는 것은 **내가 고치려는 바로 그 죄의 반복**이다.
⇒ 고치는 것은 **값이 아니라 「왜」에 대한 거짓 주장**이다.

1. `100/mult` 로 만든 「현실화율 약 N%」 **인쇄를 제거**한다. 계수는 **사전 설정된 지역별 휴리스틱 상수**이지
   측정된 현실화율이 아니므로, 그대로 말한다(§증거 규율 1 — 미측정은 "미측정"이라 쓴다).
2. 두 near-duplicate 를 **공용 헬퍼 하나로 추출**한다(버그수정 기본정책 — 한 곳을 고치면 전역이 따라오게).
3. 헤더 주석의 **거짓 밴드**(전제 2·3)를 걷어낸다 — 주석에 쓴 근거도 검증 대상이다(§C-10).
   *다음 사람이 재검증하지 않고 신뢰한다.*
4. **잠근다**(§5) — 아래 §5.

**회귀가 아닌 근거**: 반환 **계수(float)** 는 불변이므로 `estimated_market_per_sqm` ·
`total_estimated_value_won` · 매입예정가 등 **모든 수치가 그대로**다. 바뀌는 것은 사유 **문자열**뿐이고,
그 문자열은 계산에 쓰이지 않는다(전제 6~8 로 소비처 전수 확인).

## 3. ★검증하지 못한 것

- **진짜 현실화율을 재지 못했다**(미측정). 표준지공시지가↔실거래 데이터원 부재 — 별도 캠페인.
  ⇒ 계수 값 자체가 옳은지는 **이 PR 의 주장이 아니다.** 이 PR 은 «근거 없는 단정을 하지 않는다» 만 고친다.
- **라이브 화면에서 새 문구를 눈으로 확인하지 못했다**(배포 전). 배포는 통합자 소관.
- `land_prices.annotations` 를 소비하는 **저장소 밖 소비처**(있다면) 미측정.
- 지역 프리미엄이 계수에 실제로 얼마나 섞여 있는지 **불명**(원저자 의도 복원 불가) — 그래서 모델을
  다시 쓰지 않고 **주장을 걷어내는 쪽**을 골랐다.

`tests/services/land_intelligence/test_market_multiplier_rationale.py`(신규):

1. **파생형 전수** — `MARKET_MULTIPLIER_MAP` ∪ `MARKET_MULTIPLIER_REGION` **전 항목**과 폴백에 대해
   사유 문자열이 「현실화율 …%」 형태의 **수치 단정을 담지 않는다**(목록형 금지 · §수집·판정 규율).
2. **두 모집단을 가른다**(§검증 규율 2) — 등록 지역(남양주 1.2)과 **미등록 지역**(폴백 1.2)이
   **서로 다른 문자열**을 내는지. 둘이 같으면 배선을 끊어도 통과한다.
3. **공허 진리 가드** — 모집단이 비지 않았음을 **먼저** 단언(`len(...) >= 40`).
4. **계수 불변**(회귀 락) — 대표 표본의 반환 계수가 변경 전과 **같은 값**임을 못 박는다.
5. **형제 동치** — `land_price_estimator._market_multiplier` 와 comprehensive 가 **같은 헬퍼를 쓴다**
   (동일 입력 → 동일 계수). ★단순 「이름 존재」가 아니라 **행위**로 태운다(§B-8·«부른다»를 잠그지 마라).
6. ★**산문은 단언하지 않는다**(§30) — 경고 문구의 표현 자체는 다듬을 수 있어야 하므로, 락은
   **「금지된 형태가 없다」**(파생형 부정)와 **계약(계수·두 모집단 구분)** 에만 건다.

## 6. ★라이브 그라운드 트루스 (2026-09-07 · 추론이 관측이 됐다)

계획서 §1 은 **소스 대조**로 세운 것이었다. 배포된 라이브에서 직접 재니 **더 무거웠다.**

무과금 확인 먼저 — `/land-price/desk-appraisal` 은 과금 레지스트리 **미등재**(대조군: `billing_service.py`
등 존재로 조회기 생존 확인). 그래서 프로브가 보호 대상을 소비하지 않는다.

```bash
TOK=$(curl -s -X POST https://api.4t8t.net/api/v1/auth/login -H 'Content-Type: application/json' \
  -d '{"email":"admin@4t8t.net","password":"admin1234"}' | python3 -c 'import json,sys;print(json.load(sys.stdin)["access_token"])')
curl -s -X POST https://api.4t8t.net/api/v1/land-price/desk-appraisal -H "Authorization: Bearer $TOK" \
  -H 'Content-Type: application/json' -d '{"address":"경기도 남양주시 다산동 6207","area_sqm":500}'
```

### 관측 — 조작 문자열은 **가액을 곱하는 계수의 근거**였다

payload 를 파생형으로 훑어 좌표를 전수 확인했다(손으로 키를 찍지 않음). **2자리**:

| 좌표 | 내용 |
|---|---|
| `$.methods[0].rationale` | `… × 형상 0.98(준정형) × **그밖의요인 1.2(남양주시 공시지가 현실화율(약 83%) 반영 보정 1.2배)**` |
| `$.evidence.evidence[1].basis` | 동일 문자열 |

★**그밖의요인은 감정평가에서 가액을 직접 곱하는 계수다.** 즉 이것은 표시 문구 결함이 아니라
**평가 근거의 정당화가 거짓**인 것이다. 채택단가 3,718,060원/㎡ 는 그 1.2 를 곱해 나왔다.

### 그리고 **제출용 PDF 에도 실린다**

`/land-price/desk-appraisal/pdf` → 4페이지. 텍스트 추출 결과 `현실화율(약 83%) 반영 보정 1.2배` **실림**.
감정평가 성격의 제출 문서가 근거 없는 통계를 근거로 인쇄하고 있다.

★**조회기 사망을 한 번 밟았다(기록)**: 첫 추출 시도(zlib+정규식 자작)는 **길이 0** 을 냈다.
대조군 「공시지가」도 함께 비어서 «PDF 에 없다» 가 아니라 **추출기가 죽은 것**임을 즉시 갈랐다.
`pypdf` 로 되살린 뒤 대조군 3종 생존 + 없는 토큰 미검출(판별력)을 먼저 찍고 판정했다.
**본판정만 봤으면 「PDF 에 사유 없음」이라는 거짓 결함을 신고했을 것이다.**
