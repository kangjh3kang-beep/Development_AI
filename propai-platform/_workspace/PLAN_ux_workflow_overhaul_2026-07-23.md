# 사통맵 워크플로우·UX 통합 개선 실행계획 (2026-07-23)

**출처**: 사용자(부동산개발 실무자) 2차 버그리포트 — ①프로젝트 연결 전환 시 필지 잔존 ②실거래 분류별 미표기 ③가독성·직관력·편의성 부조화
**진단**: E(필지 상태 누수) · F(실거래 분류) · G(UX 정밀감사) 3레인 병렬 수행 완료

## 0. 핵심 발견 3가지

1. **필지 선택 누수는 데이터 영속 오염 등급(P0)** — 가드 전용 함수(`detachProjectCarryingSelection`)를 사용자 조작 경로가 재사용해 선택 와이프를 건너뛴다. 오염 상태로 프로젝트 생성 시 **백엔드 프로젝트 신규 생성 + 과금 + 오염 스냅샷 서버 영속**이 발생하며, 무결성 가드는 주소 일치만 보므로 **통과한다**.
2. **실거래는 그린필드 불요** — 백엔드가 이미 10종(매매 6 + 전월세 4)을 전부 수집·응답하는데, 사통맵 프론트가 `{kind:"trade", type:"apt"}` 상수로 **9종을 버린다**. 개발 실무 핵심인 **토지·상업업무용이 아예 안 보인다**.
3. **UX 부조화의 정체는 표기 문법 다중화** — 면적 5종·반경 3종·집계 표면 3~4개·컨트롤 12슬롯. 그린필드 재설계 없이 **단일화 + IA 재배치**로 해소 가능.

### 정정 사항
- 베이스맵 레일 통합(#460)은 **정상 완료·라이브 반영**됨(sw v459 번들 실증). 사용자 스크린샷의 우하단 베이스맵은 **구 SW 캐시**.
- 단, 통합 부작용: 레일 접힘(`h-28`) 시 레이어 12종이 hover/핀 뒤로 은닉 → **터치 발견성이 통합 전보다 후퇴**.

## 1. 실행 순서 (성장루프 단위)

각 레인 = 구현 → R1 적대리뷰(변이 실증) → 봉합 → CI → 머지 → 배포 → 라이브 검증.

| 레인 | 범위 | 상태 |
|---|---|---|
| **F (P0)** | 필지 선택 누수 봉합 + 계정격리 와이프 | 진행 중 |
| **G** | 실거래 유형 다중 표시 + 범례 + 절단 정직 고지 | 대기 |
| **UX-A** | 다크 대비·면적 포맷 단일화·죽은 버튼·비활성 사유 인접화 | 대기 |
| **UX-B** | IA 재배치(지도 상단화·집계 SSOT sticky·착지 지도 접기) | 대기 |
| **UX-C** | 레일 기본 확장·칩 비인터랙티브·토스트 호스트·진행 표시 | 대기 |

**보류(사전 확인 필요)**: 산출물 버튼 자동 실행(`?autorun=1`) — "무거운 분석 자동 재실행 금지"·"선택형 분석만 과금" 규약과의 충돌 여부를 먼저 판정.

## 2. 레인 F (P0) — 필지 선택 누수

**근본원인**: `SatongMapShell.tsx:698`의 사용자 조작 분기가 가드 전용 `detachProjectCarryingSelection`(`:660-665`, `prevProjectIdRef=null` 선정렬로 전환 이펙트 와이프 무력화)를 재사용.

**조치**
1. 사용자 조작 경로에서 기존 공용 `clearParcels()`(`:1241-1248`) 호출 — 목록·staged 폴리곤·상세 패널·sessionStorage 4종을 한 번에 정리하는 정본.
2. 전환 이펙트(`:1614-1617`)의 비대칭(`clearNonce` 미증가로 A→B 전환 시 A 폴리곤 잔존) 동시 해소.
3. `projectSync.clearAllProjectData`에 `SATONG_MAP_SELECTION_KEY` 추가 — 계정 전환 시 이전 계정 필지 복원 차단.
4. 무음 초기화 금지 — `connectNotice`로 고지.

**불변**: 가드 경로(`addParcels:1188`)는 정상 동작이며 기존 테스트가 고정 중 — 건드리지 않는다.

## 3. 레인 G — 실거래 유형 다중 표시

**재사용 정답 패턴**: POI 레이어(`SatongMultiMap.tsx:2185-2226`)가 이미 "켜진 카테고리 동시 순회 + 카테고리별 색상 렌더"를 구현.

**조치**
1. 마켓 이펙트를 POI 동형으로 전환 — `${type}_${kind}` 단일 조회를 다중 순회로. `MARKET_TYPE_COLORS` 6색 실사용.
2. `transactions` 레이어 컨트롤 스텁(`mapEffect:false`) → 실컨트롤 승격. 토글 엔진(`handleLayerControlClick`)은 이미 다중 선택 지원.
3. `marketLayer` 하드코딩 제거 → `layerState` SSOT 참조.
4. 색상 SSOT 통합 — `MARKET_TYPE_COLORS`(SatongMultiMap)와 `TRADE_TYPES`(NearbyTransactionsMap) 중복을 `lib/satong-map-layers.ts`로 승격.
5. 유형 범례(하단 도크) + **절단 정직 고지** — 백엔드가 이미 반환하는 `geocode_precut_count`·`coords_unresolved_count`·`radius_filtered_out_count` 표면화, 28건 캡 절단 수는 `capped_count`로 신규 반환.
6. 팝업 보강(신규 API 호출 0) — `min/max_price`·`excluded_outliers`·㎡단가. `_group_trade`가 폐기 중인 `build_year`·`jimok` 보존.
7. **`MarketInsightsWorkspaceClient.deriveResults`의 전 유형 혼합 평균 교정** — 현재 토지·상업용·아파트 단가를 한 통에 섞어 평균을 내 통계가 오도적.

**UNKNOWN**: 6유형 동시 표시 시 마커 밀집도(최대 6×28) → 클러스터링 필요 여부는 라이브 실측 후 판단. 현재 클러스터 자산 0.

## 4. UX 트랙 요약

### A (P0, 파손반경 소)
- 지도 범례 3곳 하드코딩 색 → 토큰(다크 대비 1.7:1 → AA 충족)
- 면적 포맷 5종 → `lib/formatters.ts` 단일화
- 죽은 버튼(`좌상단 멀티지도 <button>`) → 배지
- 비활성 산출물 버튼에 사유 인접 표기

### B (P0, IA)
- `/ko` 순서 반전 — 지도를 히어로 직후로(스크롤 ≈1,350px 절감)
- `ContextHeader` sticky 배선으로 집계 표면 3~4개 → 1개
- 착지 페이지 지도셸 기본 접기

### C (P1)
- 레일 기본 확장(터치 발견성 회복)
- 좌상단 칩 비인터랙티브화(조작은 레일 단일 경로)
- `useToast()` 호스트 신설 — 인라인 알림 4슬롯 흡수(분양앱 트랙 B와 동일 자산, 21탭 전파)
- `AnalysisPipelineStepbar` 배선 + 경과초 + 취소(최대 180초 무피드백 해소)
- 소요시간 문구 정직화("약 5~10초" vs 실제 타임아웃 120초)
- 검색 후보 combobox 계약(키보드 미지원 해소)

### D (P1)
- 터치 타깃 44px 하한(현재 8종 미달)
- 모바일 지도 우선 + 좌패널 바텀시트
- 지도 높이 반응형(단, `satong-map-z.ts` 계약상 500px 하한 준수)

### E (P2, codemod)
- 반경 토큰 일괄 치환 · 하드코딩 색 81개소 토큰화 · 타이포 3단 스케일 · h1 중복 해소
