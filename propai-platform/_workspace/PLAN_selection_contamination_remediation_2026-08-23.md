## 6. 해결방안

### P0-1 — 선택 오염 고지 (차단 아님)

공용 판별자 하나를 만들어 **모든 선택 진입점**이 쓰게 한다.

    lib/selection-integrity.ts
      classifySelection(parcels) → {
        spreadKm,                 // 좌표 있는 필지 간 최대거리
        regionGroups,             // 정규화 법정동 단위 군
        nonAddressRows,           // 주소 형태가 아닌 행(소유자명 등)
        zeroAreaRows,
        verdict: 'single_site' | 'multi_region' | 'malformed' | 'unknown'
      }

- `multi_region` 이면 헤더·선택 화면이 **"통합 부지가 아닙니다 — 후보지 비교로 보입니다"** 고지.
  통합면적은 계속 보여주되 **"합계(통합 부지 아님)"** 로 라벨을 바꾼다.
- **차단하지 않는다**(§4 반증).
- 계측: `selection_contamination_observation`(verdict·spreadKm·groups·nonAddressRows).
  ★상수·`service`·`surface` 를 테스트에서 함께 잠근다(3회 반복 실수).

### P0-2 — 지역 검사를 모든 진입점으로

`SatongMapShell` 의 `setSelectedParcels` **전 호출부**(실측 8곳)와
`applyRemoteSnapshot` 하이드레이션에 P0-1 판별자를 태운다.
★**파생형 락**: 진입점 목록을 코드에서 파생시켜, 새 진입점이 생기면 테스트가 실패하게 한다
(`#775` C 케이스와 같은 수법 — 사람이 센 목록이 상한이 되지 않게).

### P0-3 — 조용한 탈락 봉합 (`#772` 형제)

`auto_zoning.py` 응답에 `requested_count · resolved_count · dropped[{address, reason}]` 추가.
프론트는 `dropped` 가 비지 않으면 **고지**. ★`#772` 가 `build_integrated_context` 에서 한 것을
이 형제 함수에 미러링한다(규율 §6 미이행분).

### P0-4 — 엑셀 소유자 컬럼 오인식

`◀` 접두 + 행정구역 접미 부재 → **주소 아님**으로 판정하고 그 행을 필지로 만들지 않는다.
이미 저장된 `ad66982a` 4행 처리는 **사용자 결정 대기**(소유자 정보가 유실될 수 있어 임의 삭제 금지).
