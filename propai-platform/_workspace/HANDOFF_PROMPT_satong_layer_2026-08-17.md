## 0. ★먼저 읽을 것 — 이 세션이 낸 **오판 하나**가 하루를 잘못 이끌었다

**"SSH 키가 서버에 미인가"는 거짓이었다.** `~/.ssh/` 만 뒤지고 `Permission denied` 를
"서버에 미등록"으로 읽었다. **정답:**

```bash
ssh -i ~/.oci.key ubuntu@168.110.125.89   # → 4t8tpropai-backend-a1
ssh -i ~/.oci.key ubuntu@158.179.174.207  # → 4t8t
```

`~/.ssh/` 의 키는 **전부 거부된다**(대조군 — 그래서 조회기는 정상이었다).
이 거짓 주장으로 **사용자에게 불필요한 액션(공개키 등록)을 요구**했고, 인계서·보드·볼트
세 곳에 실릴 뻔했다. 같은 오판이 하루에 **두 세션**에서 났다(동료 `development-ai-f7` 보고).

→ **"0건은 부재가 아니다"의 SSH 판**이다. 잘못된 대상을 조회하고 부재로 결론냈다.

   라벨했다. **둘 다 대조군이 잡았다.**
