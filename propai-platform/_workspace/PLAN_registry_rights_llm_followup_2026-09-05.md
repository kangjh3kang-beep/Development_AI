# ⑥ 권리분석 LLM 추가분석 — 사용자가 **원하는 요청**으로 되묻기

사용자 요청 원문: *«해당 권리분석내용을 토대로 **LLM으로 원하는 요청으로 추가 분석**을
할수있도록 할수있을까?»* (2026-09-05 · 스크린샷 8필지 중 7성공 맥락)

## §0 옵시디언 조회 (계획게이트 §0 — 네 항목을 답한다)

| 찾을 것 | 결과 |
|---|---|
| **이미 기각된 접근** | 없음 |
| **같은 클래스의 앞선 결함** | ★**실재.** `유료·비가역_산출물_규율.md` · `2026-08-24_등기_재발급_누수와_유료길목_재사용_설계.md` — 등기부는 **1,200원/필지 유료**이고, 과거 *«해석 실패 필지가 재시도마다 재발급»* 사고가 있었다 |
| **미결·부채** | 같은 문서: *«유료 산출물은 성공/실패와 무관하게 보관한다. 실패를 캐시하기 싫으면 **파생물(해석)만** 재계산하라 — **원본을 다시 사지 마라**»* |
| **이전 판단의 근거** | 화면 상태에만 두면 새로고침으로 소실 → `registry-analysis-persistence.test.ts` 로 영속 확정 |

★★**그 규율이 이 기능의 설계를 그대로 정한다** — 추가분석은 **파생물 재계산**이므로
  **이미 저장된 분석 JSON 만** 입력으로 받고, **등기 발급 경로에 도달할 수 없어야** 한다.

## §1 전제 표 — **전부 실측**

| # | 전제 | 확인 방법 | 결과 |
|---|---|---|---|
| 1 | LLM 해석기 패턴이 있나 | `ls app/services/ai/` | ✔ **20종 이상**(`avm`·`cost`·`market`·`tax`·`esg`·`permit`…) 전부 `BaseInterpreter` 상속 |
| 2 | 권리분석용 해석기가 있나 | 같은 목록 | ✘ **없다** — 유일한 빈자리 |
| 3 | `BaseInterpreter` 가 무엇을 주나 | 원문 독스트링 | LLM 생성·호출·파싱·**TTL 캐시**·**그라운딩**(수치 인용 강제·데이터 없으면 명시) |
| 4 | 권리분석 결과 shape | `registry_analysis_service` 반환 키 | `ai`·`cached`·`generated`·`owners`·`ownership`·`ownership_form`·`mortgage`·`other_rights`·`land`·`failure_reason`·`origin` … |
| 5 | 등기부가 유료인가 | `app/core/billing.py`·`charge_idempotency.py` 실재 | ✔ **유료·멱등 과금 경로 실재** |
| 6 | 결과가 영속되나 | `registry-analysis-persistence.test.ts` | ✔ 영속(과거 소실 사고 봉합분) |

★**1·2 가 이 계획의 형태를 정한다** — *«없는 것을 만드는 것»* 이 아니라
  **«20개 형제가 쓰는 통로에 빠진 한 자리를 채우는 것»** 이다(§29).

## §2 변경 내용

1. `app/services/ai/registry_rights_interpreter.py` — `BaseInterpreter` 서브클래스.
   ★**차이점 하나**: 형제들은 **고정 해석**을 내는데, 이건 **사용자 질문**을 받는다.
   → `question` 을 프롬프트에 싣되 **데이터는 서버가 고정**한다(질문이 데이터를 못 바꾼다).
2. 라우터 `POST /registry/rights/ask` — 형제 라우터들과 같은 지연 임포트 패턴.
3. 프론트: 권리분석 결과 카드에 질문 입력 + 답변 표시.

### ★유료 차단 (이 PR 의 1급 계약)

이 경로는 **등기 발급 함수에 도달할 수 없어야 한다.**
입력은 **호출부가 이미 가진 분석 JSON** 뿐이고, 서버는 그것으로만 답한다.

### ★프롬프트 주입 (자유질의라서 새로 생기는 축)

사용자 질문이 프롬프트에 들어간다 — **형제 20종에는 없던 표면**이다.
→ 질문은 **데이터가 아니라 질문 슬롯**에만 넣고, 시스템 프롬프트가
  *«주어진 JSON 밖의 사실을 지어내지 말 것»* 을 강제한다(BaseInterpreter 그라운딩 활용).

## §3 ★검증하지 못한 것

- **LLM 응답 품질** — 실제 답변이 유용한지는 **유료 호출 없이 못 잰다**(장치 부재).
  락은 **배선과 계약**만 태운다.
- 질문 길이 상한이 실제 토큰 한도와 맞는지 — **미측정**
- 프롬프트 주입 내성의 실측 — **미측정**(정적 차단만 검증)

## §4 되돌리기

신규 파일 + 신규 라우트. 기존 경로 변경 **0** — 라우트를 빼면 원상.

## §5 잠금

1. **★유료 도달 불가** — 이 모듈의 임포트 그래프가 등기 발급 함수에 닿지 않는다(ast 파생)
2. **질문이 데이터를 대체하지 못한다** — 질문에 JSON 을 넣어도 서버 데이터가 우선
3. **형제 계약 준수** — `BaseInterpreter` 상속 · `name`·`expected_keys` 실재
4. **결측 정직** — 분석 JSON 이 실패분(`generated=False`)이면 **답하지 않고 사유를 말한다**
5. **두 모집단** — 유효 JSON ↔ 실패 JSON 이 **다른 응답**을 낸다
