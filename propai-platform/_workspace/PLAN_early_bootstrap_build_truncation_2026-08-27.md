## 2-4. 독립 리뷰가 찾은 것과 봉합 (**CRITICAL 1 + MAJOR 3**)

★**내가 만든 검증 도구 자체가 결함이었다.**

| 등급 | 발견(실측) | 봉합 |
|---|---|---|
| **CRITICAL-1** | ★**프로브가 고쳐진 배포본에서도 `exit 1`("죽음")** 을 낸다. `drain` 이 `closed=true` 로 닫으므로 카나리가 **절대 안 담긴다** → **`verdict:true` 는 「수집기가 안 돈 페이지」에서만** 나온다(**신호 반전**). 계획서의 *"자기 양성 대조군 통과"* 는 **음성 방향만** 태운 것이었다 | 판정을 **순수 함수**(`decideEarlyCaptureVerdict`)로 꺼내 **파티션형**으로: `closed===true`(수집기 인계 = 가장 강한 증거) **또는** `caught.grew`. 배포 없이 **양성/음성 둘 다** 테스트로 태운다 |
| **MAJOR-2** | AST 락이 **대리** — 선언 하나만 봐서, **중간 상수에서 잇는** 변이가 락 14/14 초록인 채 산출물을 깼다 | **파일 전체** + **파생형 대상**(layout 의 `dangerouslySetInnerHTML` 에서) + 리뷰가 규명한 **규칙 자체**를 코드화 |
| **MAJOR-3** | 네트워크·내비 실패를 **`exit 1`(=결함)** 으로 보고 — 헤더가 선언한 계약과 어긋남 | 전체 `try/catch` → **비판정 실패는 `exit 2`**(실측: 존재하지 않는 호스트 → exit 2) |
| **MAJOR-4** | 카나리가 정식 `handleWindowError` 에 잡혀 **프로덕션 텔레메트리 오염** 가능 | `closed===false` 일 때만 던진다 — 그때는 정식 핸들러가 **아직 등록 전**이다(실측 `thrown:false`) |
| MINOR | 공허한 단언(첫 단언에 함의) · 음성 대조군이 **손으로 적은 문자열** | 제거 · `themeBootstrap` 리터럴에서 **파생** |

★**내 변이에서도 하나 나왔다**: 검사기의 **재귀**(누적 좌변)를 지우는 변이가 **SURVIVED** —
대조군이 **2조각**만 봐서 3조각 이상 연결을 못 잡았다. `` `p${A}q` + `plain` + `r${A}s` `` 를 추가해
**CAUGHT 로 뒤집었다.**

★★**변이 설계도 규칙을 알아야 옳다**: 처음 넣은 변이(2조각·좌변 치환 없음)는 **SURVIVED 가 정답**
이었다 — 그 형태는 실제로 안전하다. 규칙을 모른 채 「생존 0」을 좇았으면 **멀쩡한 코드를 금지**했다.

## 3. ★검증하지 못한 것

- ~~왜 빌드가 그렇게 접는지 미상~~ → **독립 리뷰가 최소 재현으로 규명**(전제 5-b). 처방을
  *"단일 리터럴만"* 에서 **그 규칙 하나**로 좁혔다(초판은 필요 이상으로 넓어 880자 한 줄을 강제했고,
  그것이 **MAJOR-2 의 리팩토링 유인**을 만들고 있었다).
- ★**SWC 단독 `transform+minify` 로는 내 환경에서 폴딩이 재현되지 않았다**(보간이 상수 참조로 남는다).
  리뷰는 그 경로로 재현했다고 보고했으나 나는 **재현하지 못했다** — 그래서 그 방식의 락은
  **채택하지 않았다.** 대신 **규칙을 AST 로** 잠갔다. `pnpm build` 전체로는 양방향 재현·검증했다.
- `.next` 산출물 검사는 **CI 에서 안 돈다**(test 잡과 build 잡이 분리돼 있어 `.next` 가 없다).
  아래 잠금표의 AST 락이 **원인**을 막고, 산출물 확인은 **로컬 절차**로 남긴다:
  ```bash
  cd propai-platform/apps/web && pnpm build
  python3 - <<'PY'
  s=open(".next/server/pages/404.html",encoding="utf-8",errors="replace").read()
  i=s.index("__propaiEarly"); st=s.rfind("<script>",0,i); en=s.index("</script>",i)
  sc=s[st+8:en]; print(len(sc), "if(B.length<20w" in sc)   # 길이 873 · False 여야 정상
  PY
  ```
- **배포 후 라이브 확증은 아직**이다 — 이 PR 이 배포되면
  `node e2e/support/early-capture-probe.mjs` 가 **exit 0** 이어야 한다.
- 저장소의 **다른 인라인 스크립트**가 같은 형태인지는 `themeBootstrap` 하나만 확인했다
  (그것은 단일 리터럴이라 안전). 전수는 **미측정**.
