## 2. ★★내 초판의 격상 근거를 **철회**한다 — 「일방통행 문」이 아니다

초판은 *"백엔드에 이름 변경 API 가 없다 → **돈 내고 만든 것의 이름을 못 바꾼다**"* 며
이 기능을 **유료 산출물 규율 정면**으로 격상했다. **거짓이었다.**

★**원인은 패턴이 아니라 범위**다. 나는 `project_dashboard.py` 를 모집단으로 삼았는데
실제 핸들러는 `routers/projects.py` 다(`main.py:835` 가 `prefix="/api/v1/projects"` 로 등록).
**파일 하나를 모집단으로 삼았다** — 이 저장소가 오늘만 여러 번 데인 형태다.

**남는 근거(등급은 낮다)**:
- 생성이 **유료**(`POST /billing/charge · project_create`)이므로 이름이 마음에 안 들어
  **새로 만들면 또 과금**이다 — 다만 **변경이 가능**하므로 「낭비 감소」 수준이다.
- `projects/new` 정본 UX 는 **이름을 먼저 받는데** 지도 경로만 자동 파생 —
  **두 경로가 갈려 있다**(코드 주석이 *"수렴은 후속 과제"* 라 적어 둔 그 갭).
- **이름 중복 불허**(사용자 요청)는 **새 계약**이라 어차피 작업이 필요하다.

## 3. 변경 내용

1. **`createProjectFromParcels(parcels, opts?)` 에 `name` 을 선택 인자로** 추가한다.
   미지정이면 **지금의 파생 이름 그대로**(무회귀). 시그니처는 **뒤에 추가**한다 —
   앞에 넣으면 위치인자 호출부가 조용히 밀린다(이 저장소가 겪은 형태).
2. **드롭다운이 `new` 일 때만** 이름 입력을 노출한다.
   **기본값 = 파생 이름**(placeholder 가 아니라 **실제 값**으로 채운다 —
   비워 두면 「입력 안 하면 어떻게 되나」가 불명확하다).
3. **빈 값이면 파생 이름으로 되돌린다**(사용자가 지우고 그냥 진행해도 안전).
4. **길이·공백 정규화**만 한다(트림 + 상한). ★**판정한 문자열과 저장하는 문자열을 같게** 한다 —
   트림해 놓고 원본을 저장하면 판정이 아무것도 보증하지 않는다(`#944` 에서 데인 형태).
5. `projects/new` 는 **건드리지 않는다**(§0 의 기존 결정 유지). 다만 **placeholder 문구를
   그 페이지와 맞춰** 두 경로의 어휘를 수렴시킨다.

## 4. ★검증하지 못한 것

- **백엔드가 이름 길이·문자를 어떻게 제한하는지** — `POST /projects` 스키마를 아직 안 읽었다.
  **구현 착수 시 원문을 읽고** 프론트 상한을 거기에 결속시킨다(내가 지어낸 상한은 안 쓴다).
- ~~**이름 중복 허용 여부** — 미측정~~ → ★**측정했고, 결론이 뒤집혔다.**
  사용자가 **중복 불허**를 지시했고, 재보니 **막을 자리가 프론트뿐**이다:

      POST /projects 의 멱등 지문은 **주소만** 본다(독스트링 원문).
      이유: 고아 마이그레이션이 **같은 프로젝트를 재전송**하는데 본문이 다르다.
      ★그 재전송은 **같은 이름**으로 온다 → **서버 유일성 제약은 그 정당한 재전송을 거부한다.**

  → **입력 시점(프론트)에서 막는다.** 잔여(다른 탭 동시 생성)는 `PUT /{id}` 로
  **이름을 바꿀 수 있으므로**(실측) 복구 가능한 종류다.
  ★`#824` 의 *"의도적 동일주소 2건"* 과 **충돌하지 않는다** — 그건 **주소** 축이고
  이건 **이름** 축이다. 같은 주소에 다른 이름 프로젝트는 그대로 만들 수 있다.
- **로컬 이름과 백엔드 이름의 정합** — `updateProject` 로 로컬만 바꿀 수 있는 경로가 이미
  있어 갈릴 수 있다. 이 PR 은 **생성 시점**만 다루므로 그 부채는 **그대로 남는다**(명시).
- **다국어** — 이 화면의 문구가 i18n 을 타는지 미측정. 착수 시 형제 문구를 훑어 맞춘다.

## 6-B. 구현 시 태운 축 (원안)

① **기본값이 파생 이름과 같다**(입력을 안 건드리면 지금과 동일 — 무회귀 축)
② **사용자가 입력한 이름이 실제로 `POST /projects` 본문과 로컬 레코드에 실린다**
   ★「입력창이 있다」가 아니라 **「그 값이 실린다」**를 단언한다(이름만 보는 락 금지)
③ **빈 값·공백만 → 파생 이름으로 되돌린다**(두 모집단)
④ **트림한 값과 저장한 값이 같다**(판정≠소비 방지)
⑤ **드롭다운이 `new` 가 아니면 입력이 안 보인다**(음성 대조군 — 항상 보이는 구현과 구별)
⑥ ★**멱등키·인플라이트 가드가 그대로 작동한다** — 이름 입력이 리렌더를 유발해
   연타 방어가 풀리면 **과금이 두 번** 난다. 그 축을 별도로 태운다.
