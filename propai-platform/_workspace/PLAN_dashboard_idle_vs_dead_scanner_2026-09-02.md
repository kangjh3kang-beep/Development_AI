## §2 변경 내용과 **회귀가 아닌 근거**

1. `growth_stale_producer_probe.py` — `ctrl_type_total`(24h) 옆에 **`ctrl_type_alltime`** 을 함께 낸다.
   기존 키는 **이름·의미 불변**이라 이 프로브를 읽는 다른 소비처가 있어도 깨지지 않는다.
2. `integrator_dashboard.sh` ③ — 대조군 0 을 **두 경우로 가른다**:

       alltime == 0            → **술어 사망** → DEAD=1 (exit 3)  ← 종전과 동일
       alltime > 0 · 24h == 0  → **시스템 유휴** → **exit 3 아님**. 관측으로 싣는다
       24h > 0                 → 종전 판정 경로 그대로

**회귀가 아닌 근거**: 종전에 `exit 3` 이던 두 경우 중 **진짜 검사기 사망은 그대로 3** 이다.
바뀌는 것은 **유휴 케이스뿐**이고, 그 케이스는 종전에도 **아무 판정을 못 하고 있었다**(숫자를 믿지 말라고 찍었다).

★**`exit 2` 를 만들지 않는다** — `#868` 의 기각을 존중한다. 유휴는 위반이 아니다.

## §3 ★검증하지 못한 것

- **유휴가 언제 끝나는지 모른다.** 트래픽(web 세션 88→2)의 원인은 재지 않았다.
- **`exit 3` 이 실제로 무시되고 있었는지** 재지 못했다(다른 세션의 인용 이력을 못 셌다).
  내가 아는 것은 *"지금 구조상 영구히 3 이 난다"* 까지다.
- 이 변경 뒤에도 **③ 이 실제로 위반을 잡는지**는 유휴가 끝나야 태워진다 — `24h > 0` 경로는 **미태움**.
