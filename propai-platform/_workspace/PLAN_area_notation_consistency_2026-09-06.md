# 면적 표기 일관화 — **전용은 ㎡, 공급은 평형**

사용자 요청: *«전용 59㎡는 25평형, 74㎡는 30평형, 84㎡는 34평형 등으로 표시 ·
전용은 ㎡로 공급은 평형으로 병행표기하는지 분석하고 일관성을 유지»*

## §0 옵시디언·코드 조회 (계획게이트 §0 — **볼트만이 아니라 코드도**)

★오늘 §0 을 볼트에만 돌려 **이미 있는 것을 못 보고 중복을 만든** 전례가 있다
([[2026-09-05_있는_것을_못_보고_더_나쁜_것을_만들었다]]). 이번엔 **코드부터** 봤다.

| 찾을 것 | 결과 |
|---|---|
| **이미 있는 형제** | ✔ `lib/formatters.ts` — `PYEONG_SQM = 3.305785` · `formatArea()` |
| | ✔ `lib/area-ssot-contract.test.ts` — 면적 SSOT 게이트(**다필지 통합면적** 축) |
| **이미 기각된 접근** | 없음 |
| **미결·부채** | ★**내가 오늘 만든 것** — `construction-cost-params.ts` 의 `SQM_PER_PYEONG = 3.3058` 이 `formatters.PYEONG_SQM = 3.305785` 와 **두 벌**이다 |

## §1 전제 표 — **전부 실측**

| # | 전제 | 확인 | 결과 |
|---|---|---|---|
| 1 | 요청한 대응이 **순수 공식**인가 | 역산 전용률 | ✘ **관례표.** 59→25(71.4%) · 74→30(74.6%) · 84→34(74.7%) — **소형일수록 전용률이 낮다** |
| 2 | 실제 거래에 그 면적이 있나 | 남양주 8개월 469건 최빈 | ✔ **60·85·75·73·135㎡** = 59/84/74/73/134 계열 |
| 3 | 「평형」 표기가 이미 쓰이나 | 전수 | FE **22파일** · BE 4파일 (★대조군 `㎡` FE 156 · BE 157) |
| 4 | 「공급」 표기가 있나 | 전수 | FE **9파일**뿐 — 전용 178 대비 **거의 없다** |
| 5 | 평당 상수가 몇 벌인가 | `3.3058*` 전수 | ★**두 벌** — `3.305785`(formatters) ↔ `3.3058`(내 것 + BE 다수) |
| 6 | 실해가 있나 | 라이브 화면 | ✔ **있다.** 실거래 마커(전용 1,840) ↔ 분양가(공급 1,200)가 **같은 「만원/평」** 으로 나란히 — 사용자가 «왜 낮나» 로 신고 |

★**6 이 이 작업의 이유다.** 표기 통일은 미관이 아니라 **오독을 만드는 결함**이다.

## §2 변경 내용

1. `lib/area-notation.ts` (신규) — **한 곳**
   - `PYEONG_SQM` 은 **`formatters.ts` 것을 재수출**(두 벌 금지)
   - `EXCLUSIVE_TO_PYEONGHYEONG` 관례 앵커표(±허용오차로 근접 매칭)
   - 앵커 밖은 **공식 폴백**(전용 ÷ 표준전용률 ÷ 평), 그리고 **폴백임을 표기**
   - `formatExclusive(㎡)` → `"84㎡"` · `formatPyeonghyeong(㎡)` → `"34평형"`
   - `formatAreaDual(㎡)` → `"전용 84㎡ (34평형)"`
2. `construction-cost-params.ts` 의 `SQM_PER_PYEONG` 을 **제거**하고 SSOT 경유
3. 분양가 라벨에 **기준 명시** — 「평당 분양가(공급)」

## §3 ★검증하지 못한 것

- **앵커표의 완전성** — 실측 최빈 5종은 덮지만 전국 모든 평형은 미측정
- 백엔드 보고서·PDF 의 표기 통일 — **이번 범위 밖**(FE 먼저 · BE 는 별건)
- 사용자가 「25평형」을 **공급 기준으로 읽는지** — 요청문이 그 대응을 지정했으므로 그대로 따른다

## §4 되돌리기

신규 파일 + 라벨 문자열. 계산에 손대지 않는다 → **수치 변화 0**.

## §5 잠금

1. **평당 상수가 한 벌** — `3.3058`·`3.305785` **양쪽 표기**를 전수 감시(내 앞 락은 한쪽만 봐서 뚫렸다)
2. **앵커표가 사용자 지정 셋을 만족** — 59→25 · 74→30 · 84→34
3. **앵커 밖은 폴백이고 그것을 표기** — 지어낸 값과 구별
4. **전용/공급을 뒤바꾸면 실패** — 두 모집단(전용 84 ≠ 공급 84)
5. **분양가 라벨이 기준을 말한다** — 렌더 기반
