## 1. 설계사 여정 (지도 → CAD)

```
필지 선택
  → [지도] 무엇이 높이를 지배하는가 · 어디에 앉힐 수 있는가
  → [지도] 배치 3안 미리보기(판상/탑상/중정)
  → 매스 시드로 확정  →  설계 스튜디오 → CAD/BIM
```
현재 끊긴 곳: **가운데 두 칸**(지도에 일조·배치가 없음). 양 끝(필지 선택·설계 스튜디오)은 있다.

## 2. 디벨로퍼 여정

```
필지 선택
  → [지도] 지배 제약 한 줄(무엇이 발목인가)
  → [지도] 사업성 색상(수익 구간)
  → 다필지 합산 → OUTPUT DOCK 산출물
```
현재 끊긴 곳: **지배 제약**과 **사업성 색상**. 데이터는 전부 보유(`feasibility`·규제 SSOT).

---

## 3. 실행 Wave (각 독립 배포 가능·앞이 뒤의 기반)

### **W1 — 지배 제약 한 줄 + 높이 상한 통합** ★최우선
두 페르소나가 공통으로 묻는 "무엇이 발목인가"에 한 문장으로 답한다.
```
지배 제약: 군사 통제보호구역(협의 필수)
높이 상한: min(고도지구 20m, 정북일조 18m, 비행안전 30m) = 18m  ← 일조가 지배
```
- 재료: 규제 SSOT(`protection_zone_severity` — 이번 세션 신설) · `solar_envelope` · 고도지구 WMS
- 위치: 필지 상세 패널 최상단
- **신규 데이터 0** · 설계사·디벨로퍼 동시 충족

### **W2 — 경사도 필지별 표시(평균 + 분포)**
- 필지 색상 모드에 "경사도" 추가 + 상세에 `평균 18% · 최대 27%`
- ★**정직 전달 필수**: 필지 면적 < 900㎡면 `SRTM 30m 해상도 한계 — 참고값` 배지.
  `terrain_service`가 이미 confidence·note를 만들고 있으니 **버리지 말고 지도까지 옮긴다**
- 시공사에게도 바로 쓰이는 자산(2차 타깃 선투자)

### **W3 — 일조 사선 + 배치 3안 미리보기** (설계사 핵심)
- 정북 이격 필요 거리를 필지 위 반투명 밴드로
- `solar_placement_service`의 판상/탑상/중정 3안을 **2D 풋프린트**로 지도에 겹쳐 토글
  (3D는 설계 스튜디오에서 — 지도는 "어디에 몇 동"까지)
- ★부수 효과: 사용자가 지적한 **실효 건폐율** 문제가 여기서 가시화된다
  (배치엔진이 이미 "판상형 인동간격으로 28% 밀도 손실"을 계산 중인데 지금은 지도에 없음)

### **W4 — 매스 시드 인계 강화** (설계사 → CAD)
- 지도에서 고른 배치안을 `mass_seed_targets()`로 넘겨 설계 스튜디오가 이어받게
- 현재 `/design-studio` 링크는 있으나 **선택 필지·배치안이 함께 넘어가는지 미확인** → 착수 시 실측 후 봉합
- 목표: "지도에서 앉힌 대로 CAD가 시작된다"

### **W5 — 사업성 색상 + 리스크 스택** (디벨로퍼 핵심)
- 필지 색상 모드에 "사업성" 추가(개발여력 색상 문법 재사용)
- 필지 클릭 시 리스크를 막대로 쌓아 무엇이 지배적인지 즉시
- ★W1의 지배 제약을 정량으로 확장한 것 — W1 없이 하면 중복

### **W6 — 역할 프리셋**
```
설계사   일조 · 지적 · 고도지구 · 경사도
디벨로퍼 개발여력 · 용도지역 · 규제 · 사업성
```
- W1~W5로 레이어가 늘어난 뒤에 넣어야 의미 있음(지금 넣으면 고를 게 없음)

---

## 4. 순서 근거

```
W1(지배제약) → W2(경사도) → W3(일조·배치) → W4(CAD 인계) → W5(사업성) → W6(프리셋)
     ↑ 두 페르소나 공통·신규데이터0        ↑ 설계사 종착         ↑ 디벨로퍼 종착
```
- W1은 **가장 싸고 가장 넓게 쓰인다** — 먼저.
- W3→W4는 설계사 여정의 끊긴 두 칸을 순서대로 잇는다.
- W6은 마지막(고를 레이어가 충분해진 뒤).

---

## 5. 정직 경계 (이번에도 지킬 것)

- **경사도**: SRTM 30m는 대지 정지계획에 쓸 정밀도가 아니다. "참고값·실측 필요" 표기를 지도까지 반드시 전달.
- **배치 3안**: 직사각형·인동간격 근사다. 실제 설계 대안이 아니라 **볼륨 감**이다 — 문구로 명시.
- **사업성 색상**: 가정(용도·분양가)에 크게 좌우된다. 색만 보고 판단하지 않도록 가정을 배지로 노출.
- **소유자**: 등기 열람 결과를 그대로 표시하되 **벤더 마스킹을 우리가 풀지 않는다.**

## 6. 착수 전 확인할 것 (W4 관련)

지도 → 설계 스튜디오 인계가 **실제로 무엇을 넘기는지** 코드로 확인 후 W4 설계. 링크만 있고 컨텍스트가 안 넘어가면 "이어진다"는 말이 거짓이 된다(이번 세션에서 반복 확인한 orphan handoff 패턴).
