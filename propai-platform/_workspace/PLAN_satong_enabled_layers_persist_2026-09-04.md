**같은 툴바의 절반만 영속되는 비대칭**이다. `#965` 에 `it.todo` 로 남겼고 이어가라는 지시를 받았다.

## 2. 변경 내용과 **회귀가 아닌 근거**

스토어에 `enabledLayerIds: SatongMapLayerId[]` 를 두고, 컴포넌트는 **`useMemo` 로 Set 을 파생**한다.

    스토어   enabledLayerIds: ["cadastre"]  (기본)
             toggleLayerEnabled(id)   — cadastre 보호 + **변화 없으면 같은 배열 참조**
             ensureLayerEnabled(id)   — 이미 있으면 **같은 배열 참조**(P5 이식)
    컴포넌트 const ids = useSatongMapPrefs(s => s.enabledLayerIds)   // 셀렉터
             const enabledLayers = useMemo(() => new Set(ids), [ids])

- **회귀 아님**: 저장분이 없으면 기본이 `["cadastre"]` 로 종전과 동일.
- ★**P5 계약을 배열로 이식**한다 — 변화가 없으면 **같은 참조**를 돌려주므로 `useMemo` 가
  재계산하지 않고 `mapLayerState` identity 도 안 바뀐다.
- ★**오히려 개선**: `mapLayerState` 가 `Array.from(...)` 대신 **스토어 배열을 직접** 쓴다
  (P6 — 지금은 memo 가 돌 때마다 새 배열이 생긴다).

## 3. ★검증하지 못한 것 / 미리 정할 것

- **브라우저 눈 확인** — 배포 후에만.
- ★**적대 리뷰가 잡은 것 셋**(전부 반영):
  ①**배선 무잠금** — 셸의 파생 Set·`mapLayerState`·memo deps 를 끊는 변이 3종이 이 PR 의
    락 **4파일 63건을 전부 통과**했다(스토어는 완벽히 영속하는데 셸이 무시해도 초록).
    → 형제 템플릿(`persistWiring`)과 **같은 모양**으로 e2e 락 추가.
  ②**와이프 락의 축이 한 단계 위** — «`setState` 라는 문자열이 있는가» 만 봐서 내가 더한
    `enabledLayerIds:` **한 줄을 지우는 변이가 2,327건을 통과**했다. → **필드 축**으로 내렸고,
    ★그 즉시 **내가 몇 분 전에 만든 구멍**(`enabledLayersCustomized` 미리셋)을 잡았다.
  ③위 «전제 거짓»(MAJOR-3).
- ★**`isRenderableSatongMapLayer` 가드는 여전히 영속 층 밖**이다(선행 결함 — `useState` 판도
  같았다). 다만 이제 **저장까지 간다**는 점이 달라졌으므로 `merge` 에서 원소를 좁혔다.
- ★★**`#965` MAJOR-1 과 같은 축이다.** 그때 나는 «저장분이 없어도 새 객체» 를 만들어
  **전 사용자**에게 identity 교체를 일으켰다. 여기서도 같은 실수를 할 수 있으므로
  **두 모집단으로 잠근다**(변화 없음 → `toBe` · 변화 있음 → `not.toBe`).
- ★★**정정(적대 리뷰 MAJOR-3) — 이 항목의 전제가 거짓이었다.**
  초판은 *"저장분 = **사용자가 켠 것**"* 이라고 전제하고 «그대로 존중» 을 정당화했다.
  ★리뷰가 **실행으로 반증**했다 — `partialize` 가 없어 **아무 관계없는 컨트롤 변경도**
  `enabledLayerIds` 를 함께 쓴다(내가 직접 재확인: 컨트롤만 바꿔도 `["cadastre"]` 저장).
  그래서 **「한 번도 안 고름」과 「명시적으로 기본값을 고름」이 같은 모양**이 됐고,
  「선택 필지」 라벨만 끈 사용자(= `#954`/`#965` 의 **바로 그 사용자**)에게
  `defaultEnabledLayerIds()` 가 **영구히 죽는다.**
  ★이 저장소가 반복 기록한 «「모름」을 유효값으로 표현하면 관측이 된다» 그 형태다.
  → **모름을 표현 가능하게** 만들었다(`enabledLayersCustomized`). 그 플래그가 참일 때만
    저장분을 쓴다. «그대로 존중» 이라는 **결론은 유지**되고, 그것이 적용되는 **모집단이
    좁아졌다**(실제로 고른 사람만).
- **되돌리기**: `resetControlsByLayer` 와 같은 형태로 `resetEnabledLayers` 를 둔다(UI 노출은 범위 밖).

## 4. 되돌리기 경로

스토어 읽기를 `useState(() => new Set(["cadastre"]))` 로 되돌리면 종전 동작.

## 5. 잠금

| 축 | 락 |
|---|---|
| **영속** | 껐다 → 재수화 → **꺼진 채로** · **대칭**(켠 것도 켜진 채로) |
| **기본값** | 저장분 없으면 `["cadastre"]`(첫 방문 = 종전과 동일) |
| ★**identity** | 변화 없는 토글 → **같은 참조**(`toBe`) · 변화 있는 토글 → **다른 참조** |
| **계약 ①** | `cadastre` 는 꺼지지 않는다 |
| **계약 ②** | 이미 켜진 레이어에 `ensure` → 같은 참조 |
| **배선** | 셸이 **셀렉터로** 읽고 `useState` 가 **0건** |
| ★**새 레이어** | «골랐다» 가 참일 때만 저장분을 존중한다(안 고른 사용자에겐 기본값이 계속 닿는다) |
| ★**모름 표현** | 플래그 없는 저장분 → **무시** · 있는 저장분 → **사용**(두 모집단) |
| ★**플래그 발화** | 컨트롤만 바꾸면 **안 켜진다** · 실제 토글이면 켜진다 · 변화 없으면 안 켜진다 |
| ★**e2e 배선** | 화면에서 레이어를 켜면 → 스토어 → `pagehide` → **계정별 키 내용**까지 |
| ★**와이프 필드 축** | 스토어의 **비-함수 상태 키 전수**가 와이프 창에 있는가(파생) |
| ★**memo deps** | deps 에 `enabledLayerIds` 가 있는가(빈 deps 로 얼리면 실패) |
