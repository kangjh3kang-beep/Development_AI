## 2. 처방

`footer_callback(meta, font=None)` 으로 폰트를 받고 `pdf_renderer` 가 **본문과 같은 폰트**를 넘긴다.
`font=None` 이면 종전대로 폴백 — 호출부 미갱신 시 **무회귀**.

## 4. ★검증하지 못한 것 (정직)

- ~~다른 보고서 실물로 재확인하지 못했다~~ → **해소**. 동료 세션이 올바른 요청 형태를 알려 줬다.
  ★35B 의 원인은 **주소가 아니라 필드 이름**이다 — `LandReportRequest` 는 `parcels` 만 받는다
  (`routers/auto_zoning.py:2324`). `{"address": …}` 로 부르면 `parcels=[]` 가 되어
  `:2346` 의 `return {"error": "필지가 없습니다."}` = **정확히 35B**.
  올바른 본문 `{"project_name": …, "parcels": [ … ]}` 로는 **HTTP 200 · 6,787B**.
  → **엔드포인트는 정상이고 내가 계약을 틀리게 불렀다.**
  그리고 **그 PDF 도 두부다**: `land-report` **■ 32개**(쪽당 16 · 첫 줄이 내 것과 동일).
  → 파장 주장이 **코드 경로 + 실물 2종**(realtx 6쪽 114 · land-report 2쪽 32)으로 올라갔다.

- **★새로 드러난 것 — 이 파일의 락이 CI 에서 한 줄도 안 돌고 있었다(해소)**
  `pypdf` 가 **어떤 requirements 에도 없었고**(대조군 `reportlab` 은 2파일에서 검출 = 조회기 생존)
  `importorskip` 이 **모듈 레벨**이라 **파일 전체가 skip** 됐다 — `ast`/`inspect` 만 쓰는
  **배선 락까지 함께** 꺼졌다. CI `Backend (pytest)` 는 `10648 passed, 85 skipped` 로 **초록**이었다.
  ★**내 로컬이 초록이었던 이유는 내가 검증하려고 `pypdf` 를 손수 설치했기 때문**이다 —
  **같은 명령이라도 환경이 다르면 다른 게이트**다(§32).
  → ⓐ `requirements.txt`·`requirements.oracle.txt` 에 `pypdf==6.16.2` 추가
    ⓑ `importorskip` 을 `_pdf_text()` **안으로** 이동(2중 방어)
  **실측**: `pypdf` 부재 시뮬 → **3 skipped / 2 passed**(배선·무회귀 락 생존).
  수정 전에는 **5건 전부 skip** 이었다.

- **표 줄바꿈·페이지 넘김은 여전히 미측정**이다 — 인계서가 적은 항목 중 폰트만 갚았다.
