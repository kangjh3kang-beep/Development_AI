### ★계수는 방법이 값을 가른다 — 값 대신 명령을 적는다

```bash

git grep -cF  '168.110.125.89' | awk -F: '{s+=$NF} END{print s}'   # 매치 줄 수
```

**「N회」를 인용할 때는 어느 계수인지 적어야** 다음 사람이 대조할 수 있다.
★그리고 **`-F`(고정 문자열)를 쓴다** — IP 를 정규식으로 주면 `.` 이 임의 문자를 먹는다.

## 2. 변경 내용과 그것이 회귀가 아닌 근거

`propai-platform/tests/test_host_address_ssot.py` 신설:

1. **SSOT 선언** — 정본 호스트를 `LIVE` / `RETIRED` 로 **상태와 함께** 선언하고,
   각 항목에 **재측정 명령**을 적는다(값만 적으면 다음 사람이 재검증하지 않는다).
2. **파생형 수집** — `git ls-files` 로 **실행되는 매체**(`.sh .py .yml .yaml .ps1 .ts .tsx`)를
   전수 훑는다. 목록형이 아니므로 새 스크립트가 자동으로 감시망에 들어온다.
3. **판정** — 공개 IP 리터럴은 `LIVE` 집합에 있어야 한다.
   `RETIRED`(예: 죽은 `134.185.104.167`)가 실행 매체에 있으면 **위반**이다.
   예약·사설·문서용 대역(RFC1918·loopback·link-local·TEST-NET·CGNAT)은 **위반이 아니다**.
4. **음성 대조군** — 정본 주소를 담은 문자열은 위반이 **아니어야** 한다
   (없으면 「전부 차단」이 만점이 된다).
5. **수집기 생존** — 훑은 파일 수와 **정본 주소를 실제로 찾았는지**를 먼저 단언한다
   (공허 진리 방지: 「위반 0」이 「대상 0」이면 무의미하다).

**회귀가 아닌 근거**: 런타임 코드를 건드리지 않는다(테스트 신설). 현재 실행 매체에
`RETIRED` 주소가 있으면 이 락은 **처음부터 빨갛다** — 그 경우 그 파일도 같은 PR 에서 고친다.

## 3. ★검증하지 못한 것

- **`134.185.104.167` 이 「죽었다」가 영구인지 일시인지** — tcp 22 한 시점 관측이다.
  그래서 삭제가 아니라 **`RETIRED` 로 선언**하고, 되살아나면 선언을 되돌리면 된다.
- **`md` 를 제외한 결정의 비용** — 문서에 오주소가 커밋되면 이 락은 안 잡는다.
  동료 세션의 PreToolUse 훅이 그 매체를 덮지만, **훅의 다수결 자체가 저장소 파일에서 나오므로**
  문서 오염이 훅을 오염시킬 수 있다. **미측정**: 몇 건이면 다수결이 뒤집히는지.
- **이 락이 오늘의 3회 중 몇 건을 잡았을지** — 셋 다 **즉석 Bash 명령**이었으므로
  ★**이 락 단독으로는 0건**이다. 이 락이 막는 것은 *"그 오주소가 스크립트에 커밋되는 것"* 이고,
  즉석 명령은 동료의 훅이 막는다. **두 매체가 서로를 대체하지 못한다.**
