# 볼트 대기열 — D: 접근 불가로 옵시디언에 못 쓴 기록 (2026-09-09 · sid=ad208019)

## 왜 여기 있나

옵시디언 Vault(`/mnt/d/옵시디언기록/…`)에 쓰려 했으나 **D: 전체가 접근 불가**다.
전역 규칙이 *"접근 불가 시 다른 위치 대체 저장 금지, 실패 경로만 보고"* 라
볼트 문서를 임의 위치에 흩뿌리지 않고 **여기 한 곳**에 모은다.
D: 가 돌아오면 이 디렉토리 내용을 볼트로 옮기고 디렉토리를 지운다.

★09-08 분(`vault_pending_2026-09-08_ad20/`)은 **다른 워크트리**(`Development_AI_stage1_commission`,
브랜치 `fix/commission-orphan-node-integrity`)에 있다. 둘 다 옮겨야 한다.

## 재측정 이력 (라벨을 승계하지 않는다)

| 시각 | D: 상태 | 대조군 `/mnt/c` |
|---|---|---|
| 2026-09-08 18:2x | `No such device` | 정상 |
| 2026-09-08 18:5x | `No such device` | 정상 |
| **2026-09-09 03:5x** | `No such device` | **정상** |

`mount` 에 9p 항목은 **살아 있다** — 마운트가 아니라 **전송이 죽었다**
(`ls` 실패는 증상이지 원인이 아니다). 대조군이 `/mnt/c` 에서 통과하므로
도구·경로·권한 문제가 아니다.

## 처방 (사용자 판단 필요 — 실행하지 않았다)

Windows 호스트에서 `wsl --shutdown` 후 재진입. **이 세션을 종료시키므로 실행하지 않았다.**
★D: 는 2026-09-05 이후 `Full Repair Needed` + 일부 파일 CRC 오류 이력이 있다.
`chkdsk /f D:` 는 길고 되돌리기 어려워 **사용자 결정 사항**으로 남긴다.
