## §2 변경 내용 — 넷

### 2-⓪ ★배치 재실행 중복 봉합 (P9 · **차단 결함**)

**근본원인**: `parcel_batch.py` 가 멱등으로 **기존 잡을 받아 놓고도** `run()` 을 무조건 예약하고,
`batch_service.py:202` `on_chunk` 이 `items.extend()` 로 **덧붙인다**.

**처방 둘** — 서로를 대신하지 못한다:
- `run()` 시작 시 `items` 를 **비운다** → **정확성**. `run_chunks` 는 언제나 전체를 다시 도므로
  누적은 언제나 오염이다. 이러면 **Celery 재시도**도 함께 보호된다.
- 라우터가 **터미널 잡을 재실행하지 않는다** → **비용**. 206필지면 외부호출 206건이 통째로 낭비된다.

### 2-a ★공용 투영 — **두 파이프를 함께** 고친다(전역 전파방지)

`app/utils/land_characteristics.py::project_land_characteristics` 신설.
`job_runner`(batch)·`_enrich_fill`(excel) **둘 다** 이것을 쓴다.
★한쪽만 넓히면 **두 파이프의 필드 집합이 갈라진다** — 같은 필지가 진입점에 따라 다른 내용을 갖는다.
★**파생형**이다(원천 dict 를 그대로 옮기고 `_DROP` 에 적은 것만 뺀다 — 사유 명시).

### 2-b 기존 `land_adapter` §2 에 **행 3개** 추가 (진짜 신규는 이것뿐)

`필지 면적 분포`(평균·최소·최대 + **산정 n/N**) · `지목 분포`(+ **미상 n필지**) ·
`맹지(도로 미접)`(맹지 / 접도 / **미상** 3분할).
★**맹지 판정은 `_is_maengji` 를 재사용**한다(P8).
★**신규 파일 아님** — 기존 보고서(PDF/PPTX/DOCX 3포맷·프론트 배선 완료)가 그대로 담는다.

### 2-c 삭제한 것

「규제 중첩」 — **원천이 없다**(§0-b). 없는 채로 구현하면 *"규제 중첩 0건"* 이 **항상** 출력돼
사용자가 **「규제 없음」으로 읽는다**. 그건 무날조 규율 정면 위반이다.

## §4 ★검증하지 못한 것

- ★★**P6 이 틀렸다.** 나는 *"토지대장 원천 0건"* 이라 적었는데 그것은 **저장소를 뒤진 결과**였지
  「원천이 없다」가 아니었다. **사용자가 VWorld 카탈로그에서 `ladfrlList` 를 찾아 줬다.**
  **「0건」은 조회 결과이지 결론이 아니다** — 오늘 이 교훈을 세 번 적어 놓고 네 번째로 밟았다.
  → 이 PR 에 `get_land_ledger_list` 를 넣었다(소유구분·**공유인수**·대장구분·데이터기준일자).
- **소유자 성명은 여전히 범위 밖**이다 — `ladfrlList` 는 *"소유자 개인정보를 **제외한**"* API 다.
  성명·지분·권리관계는 등기부(유료) 소관이고, 기존 §3 고지가 이미 그것을 말한다.
- ★**`ladfrlList` 의 응답 래퍼 키는 미측정**이다(문서에서 확인 못 함). 이름을 지어내지 않고
  **구조로 찾는 파서**를 썼고 그 파서를 락으로 잠갔다. **라이브 1회 호출로 확증이 필요**하다.
  ★**제품 이름을 「토지대장 분석보고서」로 부르지 않는다** — 원천이 NED 토지특성이라
  그 이름은 소유자·연혁을 포함한다고 오독된다(리뷰 M2 수용). 기존 이름(`land-report`)을 유지한다.
- **집계 단계(`aggregator`) 성능 미측정** — 필지당 순차 `get_land_use_districts` 가 있다(리뷰 M3).
  이 PR 이 만든 것이 아니고 건드리지도 않았다.
- **`land_use_situation`·`terrain_*` 은 실었지만 표에 칸이 없다** — 소비처 0. 이번엔 **의도적**이다
  (표를 넓히는 것은 별건). 다만 그렇게 **적어 둔다**.
- **`_enrich_fill` 확장의 라이브 검증 미실시** — 단위 테스트로만 잠갔다.
- **연도 혼재 미고지** — `_first_year_with_data` 는 필지마다 다른 연도를 줄 수 있는데
  「총 공시가액」이 연도 섞인 합이 된다. **이번 범위 밖**(리뷰 지적 수용, 후속).
- 기존 `land-report` 의 **120필지 캡**과 배치 206건의 불일치 — 손대지 않았다.
