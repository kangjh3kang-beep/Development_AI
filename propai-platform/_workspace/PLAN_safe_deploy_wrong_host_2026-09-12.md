# `safe-deploy.sh` — **「기계가 틀렸다」를 「경로가 틀렸다」로 읽게 만든 한 문구**

## 0. 옵시디언 조회 결과

SessionStart 훅이 주입한 것 외에 **주제어로 별도 조회**했다(`safe-deploy`·`배포 경로`·`A1`).

| 찾을 것 | 결과 |
|---|---|
| 이미 기각된 접근 | **없음** — 이 파일의 경로 상수를 손댄 기록이 볼트에 0건 |
| 같은 클래스의 앞선 결함 | **있음** — 「사유 넷에 문구 하나면 사람을 틀린 곳으로 보낸다」(토스 키 검사, 축이 하나가 아니었다) · 「배포됐다 ≠ 작동한다」에서 **잰 매체가 틀린** 형태 |
| 미결·부채 | `#1029` 가 자동배포 트리거를 지웠다 → **수동 `safe-deploy.sh` 가 유일 경로**가 됐다. 이 파일의 실패 문구 중요도가 그때 올라갔는데 아무도 안 봤다 |
| 이전 판단의 근거 | 인계서의 *"Path Resolution Error"* — **근거가 로컬 `ls` 였다**(A1 미측정) |

## 1. 전제 표 (★결과 칸은 **실제 측정값**)

| 전제 | 확인 방법 | 결과 |
|---|---|---|
| A1 에 `$HOME/Development_AI` 가 있다 | `ssh ubuntu@<A1> 'ls -d $HOME/Development_AI'` | **`/home/ubuntu/Development_AI`** (실재) |
| A1 에 `My_Projects/` 중첩이 있다 | 같은 세션 `ls -d $HOME/My_Projects/Development_AI` | **없음** (`No such file`) |

★**전제 하나가 뒤집혔다**: *"경로 상수가 틀렸다"* 는 **거짓**이고, 그 근거는 **다른 호스트를 잰 것**이었다.

## 2. 변경 내용과 **회귀가 아닌 근거**

`$REPO` **부재 시** 프리플라이트를 넣어 두 사건을 가른다.

| 상황 | 종전 | 이후 |
|---|---|---|
| A1 아님(중첩 경로 보임) | `FAIL cd-repo` · exit 1 | **`ABORT wrong-host(A1 아님)` · exit 8** + 「상수를 고치지 마라」 |
| A1 인데 경로 없음 | `FAIL cd-repo` · exit 1 | `FAIL repo-missing($REPO)` · exit 1 |
| A1 · 정상 | (그대로) | **그대로** — 가드가 발화하지 않음(특이도 실측) |

★**회귀가 아닌 근거**: ①`REPO` 상수를 **건드리지 않았다**(락이 그 불변을 감시) ②가드는
`[ ! -d "$REPO" ]` **안에서만** 돈다 — A1 정상 경로에서는 **한 줄도 실행되지 않는다**
③특이도 테스트가 A1 모사 HOME 에서 **가드를 지나 뒤 단계로 가는 것**을 확인했다.

## 3. ★검증하지 못한 것

- **A1 에서 이 스크립트를 실제로 돌려 보지 않았다.** 로컬에서 두 분기와 특이도만 태웠다.
  A1 실행은 **프로덕션 배포**이고 이 PR 의 범위가 아니다 — 배포는 통합자 몫이다.
- ~~다른 배포 스크립트에 같은 형태가 있는지 미측정~~ → **★쟀다(아래 §6).**
- 인계서에 그 거짓 진단이 남아 있다 — **보드에 정정 NOTE 를 올렸다**(문서 자체는 세션 산출물이라
  내가 고치지 않는다).

## 4. 되돌리기

프리플라이트 블록(연속된 한 덩어리) 삭제로 되돌아간다. `REPO` 상수는 변경이 없으므로
되돌릴 것이 없다. 테스트 파일은 신규라 삭제로 되돌아간다.

## ★★8. 2026-09-12 20:1x — **귀속 정정**(협업이 잡았다)

### ① 「동료가 틀린 진단을 인계했다」는 **내 서술이 틀렸다**

통합자 세션 본인 확인:

> *"Path Resolution Error … Hardcoded …" 는 **자동 요약이 붙인 라벨**이고, 내가 보드에
> 실제로 쓴 것은 «그 스크립트는 158 에서 도는 것입니다» 였다.*

⇒ **그 세션은 처음부터 옳았다.** 내 A1 실측은 그 진단을 **반증한 것이 아니라 확증**한 것이다.

★***이게 이 결함의 더 나쁜 얼굴이다*** — 옳게 쓴 사람의 진술조차, **실패 문구가 모호하면
요약 한 단계에서 뒤집힌다**. 그리고 **세 세션이 그 뒤집힌 라벨 위에서 각자 판단했다.**
고칠 것은 사람이 아니라 **문구**다. 처방은 그대로 유효하고, **이유가 더 강해졌다.**

### ② 근거를 **양방향**으로 바꿨다(동료 4e 실측 채택)

| 호스트 | `$HOME/Development_AI` | `$HOME/My_Projects/Development_AI` |
|---|---|---|
| A1(프로덕션) | **실재** | 없음 |
| 개발 머신 | 없음 | **실재** |

**둘 다 참이다.** 내 원래 근거(«A1 에 그 경로가 있다»)는 **한 방향만** 막았다.
**«그 값은 호스트 의존이다»** 가 양방향을 막는다 — 다음 사람이 **반대 방향으로** 고치는 것까지.

### ③ ★내가 이 과정에서 **두 번 틀렸다**(기록해 둔다)

1. **「claim 은 고아」** — 이름·소켓 부재 두 축으로 단정했는데 **그 세션은 개명했다**
   (`a4`→`61` · 소켓 `3844825`→`3100`). ***«A 의 증거가 약하다» ≠ «¬A 가 참이다».***
   ★「이름 부재 ≠ 세션 사망」 전례를 **인용하면서** 밟았고, 그 전례의 당사자가 본인이었다.
2. **「mtime 은 판별력 0」** — 대조군을 댔다고 했는데 **살아 있는 세션만** 넣었다(모집단 하나).
   죽은 세션을 넣으니 **00:48~03:33 ↔ 20:1x** 로 깨끗이 갈렸다.
   ***«픽스처는 두 모집단을 갈라야 한다»*** 를 인용하는 문장 안에서 어겼다.
   ★그리고 「소켓 5 == 세션 5」로 **수는 검산했는데 대응을 안 만들어서** 그 5 안에 본인이
   있는 줄 몰랐다 — ***수를 세는 것과 대응시키는 것은 다르다.***

### ④ 배포 축 — **커밋 미배포 ≠ 런타임 뒤처짐**

통합자 실측(20:01): 런타임 델타 **web 9파일 · api 0파일**.
`#1030`/`#1025` 의 api 변경은 **이미 168 에 반영**돼 있다(표식 `propai-v002978-8f566196`).
⇒ 미배포 커밋은 5건이지만 **구울 것은 158 web 단독**이다.
***커밋이 미배포로 보이는 것과 런타임이 뒤처진 것은 다른 명제다*** — 축별 델타로 재라.

★**다만 리뷰어가 든 두 시나리오는 사실 같은 사건이었다**(둘 다 `self_repo != repo`).
R1 의 두 이름은 **「부재로부터 유도」가 만든 인공물**이고, 그것을 없앤 것이 MAJOR-1 의 수정이다.
**합쳐진 것 자체는 옳았다** — 틀린 것은 «잰 값을 안 쓴다» 였다.

★**갈라 두니 도달 불가 분기가 스스로 드러났다**: `repo-missing` 은 «`$REPO` 가 없다» 와
«`self_repo == $REPO`» 를 동시에 요구하는데, 이 스크립트는 `$REPO` **안**에 있으므로
경합 말고는 도달 불가다. → **strict xfail 로 초록 안에** 남겼다(커밋 메시지에만 적으면
다음 사람이 「검증됐다」고 읽는다).

### MINOR-1 — **지금 장식인 예외는 나중에 서식지가 된다**

`own.discard("12")` 는 **무동작**이었다(실측 `guard_codes == {'11'}` 이라 교집합에 12 가
들어올 일이 없다). 그런데 가드가 언젠가 12 를 쓰면 그 discard 가 **진짜 충돌을 조용히 지운다.**
⇒ 두 줄 삭제. ***지금 아무것도 안 하는 예외를 남겨 두지 않는다.***

M12(전제 파괴)가 그 축을 덮는다.

## 11. ★A1 실행 0회 — **「미측정」이지 「검증됨」이 아니다**

R1 에서는 «A1 무영향»이 **구조적으로 참**이었다(`[ -d "$repo" ] && return 0` 이라 한 줄도
안 돈다). R2·R3 는 `pwd -P`·`BASH_SOURCE` 해석이 **A1 에서만 참이 되는 조건**을 쓴다.
⇒ 그 근거가 **약해졌다**(0c 지적 · 통합자 인정). 통합자가 **배포 주기에서 갚기로** 했다 —
A1 에서 `assert_a1_host "$HOME/Development_AI" ""` 가 **아무것도 안 하는 것**을 실측해 보드에 남긴다.
그때까지 이 칸은 **미측정**이다.
