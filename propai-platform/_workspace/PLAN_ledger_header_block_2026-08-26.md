## 2. 변경 내용

`HEADER_SPECS`(라벨·경로·단위) → `build_header()` → 응답 `legacy_ledger.header`.
화면은 표 **위**에 격자로, 인쇄본은 §5 표 **앞**에 KV 표로.

### 회귀가 아닌 근거

- `header` 는 **신규 키**(additive). 기존 소비처 무영향.
- 화면·인쇄본 모두 **제원이 없으면 블록을 만들지 않는다** → 기존 렌더 무변화.
- 실측: 백엔드 **58 passed / 1 skipped** · 프론트 **5파일 39 passed** · ruff·tsc·eslint 0.

## 3. ★검증하지 못한 것

1. **라이브 종단** — 배포 후.
2. **원본 21항목 중 7항목은 만들지 않는다**(전제 ⓒ). *"제원을 재현했다"* 고 **주장하지 않는다** —
   **빈 행을 만들면 화면에서 「0」이나 「미정」으로 읽힌다.**
3. `금융조달규모` — `cashflow.summary` 에 `pf_loan`/`bridge_loan` 이 **라이브에서 비어 있었다**.
   경로만 만들지 않고 **항목 자체를 뺐다**(있는 척하지 않는다).
4. ★**부채**: 두 테스트 파일이 **각자** 시나리오 픽스처를 들어, 한쪽만 넓히면 다른 쪽이 좁게 남는다.
   이 세션에서 **세 번** 밟았다. `@pytest.mark.skip` 으로 **초록 안에 보이게** 남겼다.

## 4. 되돌리기 경로

`HEADER_SPECS`·`build_header`·응답 키 제거 + 표시층 2곳. 3파일.

## 5. 잠금

| 축 | 검사 |
|---|---|
| **파생형** | 모집단이 `HEADER_SPECS` 에서 파생 · 명세에 없는 라벨이 나오면 실패 |
| **빈 행 금지** | 값이 없으면 **행을 만들지 않는다**(빈 시나리오 → `[]`) |
| **두 모집단** | 완전 시나리오는 8행 이상 / 빈 시나리오는 0행 · 화면·인쇄본 모두 **블록 자체가 없다** |
| 표기 | 단위·수치여부를 함께 싣는다 · **수치/문자가 갈린다**(전부 True 인 구현 배제) |

| **매체 셋** | 응답·화면·**인쇄본** 각각 락(★#110 의 교훈 — 화면만 잠그지 않는다) |
