### ★P1·P2 가 이 PR 의 근거다

데이터는 **이미 호출부에 있다.** 한 줄 아래에서 버려질 뿐이다 — **신규 API 호출 0**.

### ★왜 사용자가 「토지」로 읽었나 (P8·P9 의 귀결)

한 팝업 안에 **토지 형태와 건물 형태가 섞여** 있는데 **무엇인지는 안 적혀 있다**:

| 줄 | 성격 |
|---|---|
| `화도읍 창현리 736-1` | 지번 — **토지 주소 형태** |
| `용도지역 근린상업` · `지목` | 토지 속성(그런데 P9 대로 건물 거래에도 정당하게 붙는다) |
| `2012년 준공` · `8층/9층/10층` | **건물** 속성 |
| `평균 9.8평` | 건물이면 전용면적, 토지면 거래면적 — **같은 라벨이 다른 것을 뜻한다** |

⇒ 사용자가 알아챈 근거는 **층수뿐**이었다. 화면이 알려 준 것이 아니다.

## 2. 변경 내용과 **회귀가 아닌 근거**

### 2-a. `marketPopupHtml` 에 유형을 넘기고 **텍스트로** 렌더한다

`marketPopupHtml(group, kind)` → `marketPopupHtml(group, kind, type)`.
라벨은 `MARKET_TYPE_LABELS`(`satong-map-layers.ts:305` — `MARKET_TRADE_TYPES` 에서 **파생**)에서 얻는다.
**새 어휘를 만들지 않는다.**

회귀가 아닌 근거: 호출부에 이미 있는 값을 **한 인자 더** 넘길 뿐이고, 데이터 흐름·API 호출·저장 스키마
변경이 **0**이다. 유형이 없으면(미지의 키) **아무것도 찍지 않는다**(무날조).

### 2-b. ★`marketPopupHtml` 을 **export** 한다 — 소스 스캔이 아니라 **행위 락**을 쓰려고

이 저장소는 `SatongMultiMap` 에 **Leaflet 목이 없어** effect 본체가 테스트에서 한 번도 안 돈다
(#1012 실측: 그 안의 `false` 변이가 **64파일 468건을 전부 통과**했다). 그래서 기존 팝업 락은
`satong-map-honesty-wiring.test.ts` 의 **소스 문자열 검사**다 — 주석·문자열에 뚫린다.

순수 함수를 export 하면 **HTML 산출물을 직접 태울 수 있다**. 형제 선례: `buildOverlayNotes`(#1012에서
같은 이유로 순수화), `resolveSatongOverlayPlan`.

### 2-c. P8 의 거짓 주석을 정정한다

`molit_client.py:465` 의 *"토지 매매(getRTMSDataSvcLandTrade) 전용"* → **전 유형에서 파싱된다**로.
★다음 사람이 그 문장을 근거로 «건물엔 안 온다»고 판단하면 틀린다(§C-10).

### 2-d. ★하지 않는 것

- **`지목·용도지역`을 건물 거래에서 걷어내지 않는다**(P9 — 정당한 데이터다). 결함은 필드가 아니라 **유형 미표기**다.
- **마커 색·범례를 바꾸지 않는다**(대리 변수를 없애는 게 아니라 **정본 표기를 더한다**).
- **마커 라벨은 이 PR 에서 안 건드린다** — 라벨 버짓·겹침 규약이 따로 있고(`labelPlan`),
  거기 유형을 넣으면 그 계약을 함께 봐야 한다. **미해결로 `it.todo`.**
- 백엔드 변경 **0**.

## 3. ★검증하지 못한 것

1. **브라우저 실측 없음** — 배포 후에만 가능. 락은 순수 함수 행위 락으로 건다.
2. **`평균 N평`의 의미가 유형마다 다르다**(건물=전용면적 / 토지=거래면적)는 것을 이 PR 은
   **표기로 해소하지 않는다** — 유형을 적으면 사용자가 해석할 수 있게 되지만, 라벨 자체는 그대로다.
   **미해결**로 `it.todo`.
3. **`officetel` 인지 `commercial` 인지는 스크린샷만으로 확정 못 했다** — 마커 색이 분홍이라
   `commercial`(`#ec4899`)로 **보이지만**(추론), 확정하려면 범례 대조가 필요하고 **그것이 이 결함이다.**
4. 성장루프 인접 관측: `/api/v1/auth/me` 가 `latency_regression` **warn**. 이 PR 과 **인과 없음**(백엔드 변경 0).
