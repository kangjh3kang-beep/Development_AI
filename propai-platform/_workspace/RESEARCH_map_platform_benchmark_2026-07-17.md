## 1. 플랫폼별 핵심

### 밸류맵 (valueupmap.com)
- 실거래 **가격 마커**(줌 레벨별 밀도), 마커 클릭 → 거래 이력 패널. 멸실 건물 과거 실거래도 표시.
- 데이터: 토지·단독/다가구·상업·공장 실거래, 매물, 경매 감정가/낙찰가.
- 차별화: **AI 건축설계(가설계)** — 6개 유형·최대 10개 설계안(면적·주차·일조·도면)·CAD 다운로드, 1회 ~5만원.
- 출처: valueupmap.com · houseinfo.kr/blog/20004-valuemap-realestate [verified] · financeblog.co.kr/부동산-밸류맵 [verified] · 한경 202209135806i

### 랜드북 (landbook.net)
- 실거래+**AI 추정가**+신축이력. **준공연차·면적 필터**로 "신축 가능한 땅" 탐색(개발 관점 필터).
- 필지 선택 → AI 건축분석: 조건 입력 → 법적 범위 내 수익최적 설계안 **3D 11종**(배치/평면/단면/투시) → 임대료/분양가 예측 → 수익 추정. "30분 신축 사업성검토".
- 소형주택 무료·상업/오피스텔 과금. 범위 70~400㎡, 수도권+5대 광역시+제주. B2B=LBDeveloper.
- 출처: landbook.net/service/ai-analytics [verified] · wiki1.kr/index.php/랜드북 [verified]

### 디스코 (disco.re)
- **필지 클릭 = 통합 패널**(실거래·토지대장·건축물대장·개별공시지가·토지이용계획) — 업계 기준선.
- 실거래 3,000만건+, 등기변동 알림, 경매, 용도지역·인구밀도 레이어, 면적재기.
- 출처: disco.re · App Store 디스코 [verified] · acase.co.kr/10719 [verified]

### 부동산플래닛 (bdsplanet.com)
- **노후도(건축연한) 지도** 대표기능. 가격변동 코로플레스(파랑=하락·빨강=상승).
- **구역 그리기(polygon draw) + 경계 드래그 편입/제외 → 구역 노후도·용도·구조 통계 자동 산출** = 재개발 요건 검토를 지도에서 완결.
- 유료: 탐색플러스 구독.
- 출처: bdsplanet.com/map/realprice_map.ytp · 이용안내 guide.ytp

### 호갱노노 (hogangnono.com)
- 단지 가격 라벨 마커 + **줌아웃 시 지역 평균 자동 롤업**.
- **분석 오버레이 단일 토글 세트**(업계 레퍼런스): 경사도·학원가 히트맵·상권·입주물량·개발호재·분위지도. "모든 분석을 별도 페이지가 아닌 지도 오버레이로".
- 필터 저장 → 조건 충족 단지만 지도에 남김. 커뮤니티(거주민 리뷰) 결합.
- 출처: hogangnono.com · redbusbagman.com/powerofhgnn [verified]

### 네이버부동산 / 카카오맵 지적편집도
- 카카오: 레이어 버튼 → 지적편집도 토글 — **용도지역 색상 폴리곤**(표준화된 컬러), 국토계획 서브토글, 면적재기.
- 네이버: 매물 라벨 + 탭형 레이어(개발/학군/편의/지하철), 개발 탭=공공 고시 기반 도로·철도·지구.
- 출처: gureugi.com 지적도 가이드 [verified] · teamup.kr 네이버부동산 [verified]

### 해외 — Regrid · Reonomy · LightBox Vision
- **Regrid**: 필지 하이라이트 + Layers 토글(조닝·홍수·인구·기회지역 등), **플로팅 라벨+조합 규칙**(동시표시 제한으로 과밀 방지), 필지 노트/사진 부착, **Project 저장·공유**(레이어+스타일+뷰 번들).
- **Reonomy**: 200+ 필터, 반경/그리기 영역검색, ML **likely-to-sell 점수**, LLC 실소유자 언락.
- **LightBox Vision**: 필지 300+속성, 조닝 오버레이+PZR 자동보고서, **Assemblage(합필 조합) 탐지**, 부채/거래이력 필터.
- 출처: support.regrid.com/property-app/layers [verified] · reonomy.com/solutions/web-application [verified] · lightboxre.com/data/lightbox-vision [verified]

## 2. 업계 공통 패턴 (7문법)

①필지 클릭=통합 정보 패널 ②가격/지표 라벨 + 줌 롤업 ③용도지역 색상 오버레이
④히트맵/코로플레스 토글 세트 ⑤필터→지도 반영 ⑥검색→상세→심화분석 퍼널(원클릭 진입)
⑦관심물건 변동 알림 루프. (+지도 그리기 도구, 시계열 인패널 그래프, 무료탐색+유료심화 과금)

## 3. 사통팔땅 차용 우선순위 Top 10

1. 구역 그리기+경계 편입/제외(부동산플래닛) → 다필지 선택 UX 상위호환
2. 필지 클릭 통합 사이드패널(디스코/Regrid)
3. Assemblage 합필 조합 탐지(LightBox) → 국내 부재
4. 분석 오버레이 토글 세트+히트맵(호갱노노 문법)
5. 줌 레벨별 지표 롤업 마커(호갱노노/밸류맵)
6. 플로팅 라벨+조합 규칙(Regrid) → 라벨 과밀의 검증된 해법
7. 필지 노트·사진+프로젝트 저장/공유(Regrid)
8. 등기/실거래 변동 알림(디스코) → land banking 리텐션
9. 개발 관점 탐색 필터(랜드북 준공연차·면적 / Reonomy 보유기간)
10. 지도 내 심화분석 원클릭(밸류맵 가설계 / 랜드북 신축분석 퍼널)

## 4. 개발사업 특화 기회 (어느 플랫폼도 없음)

1. **파이프라인 맵** — 후보검토→매입→인허가→착공→분양 단계를 필지 색상/뱃지로(전주기 포트폴리오 지도)
2. **실효 용적률(7계층 min) 개발여력 히트맵** — 법정 아닌 실효FAR와 현황 연면적의 갭 = "못 지은 땅" 발굴(calc_effective_far 보유)
3. **규제·인허가 리스크 오버레이** — 개발행위허가·경사도·영향권 신호등(토지이음엔 지도 UX 없음, 카카오는 용도지역만)
4. **다필지 합필 What-if 장바구니** — 담을 때마다 통합 수지·규모 실시간 재계산(다필지 통합분석+개략수지 보유)
5. **공공입찰·공매 기회 레이어** — G2B/온비드 물건 지도化 + 클릭 시 적정투찰가 분석(G2B 6엔진 보유)
