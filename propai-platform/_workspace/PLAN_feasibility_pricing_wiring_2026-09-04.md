## 2. 변경 내용 — **네 단계**, 각 단계가 독립 배포 가능

> ★**대원칙**: 요구 6개 중 **4개는 이미 구현돼 있고 「안 불릴」 뿐**이다.
> 없는 것을 만들기 전에 **배선을 고친다.** 새 엔진을 만들면 그것이 다음 결함의 서식지가 된다.

### P0 — 시드 경로를 실거래로 (요구 ①②·지출 토지비)

**문제**: 같은 현장이 **경로에 따라 다른 분양가**를 낸다(A3).
**처방**: `baseline_feasibility()` 가 `rough` 와 **같은 우선순위**를 쓰게 한다 —
`suggest_base_price` → `_trade_per_pyeong` → 지역테이블(«추정·비실거래» 라벨 유지).

★**새 우선순위를 만들지 않는다.** `rough_feasibility_orchestrator.py:145-167` 의 것을
**공용 함수로 추출**해 두 경로가 같은 것을 부르게 한다(버그수정 기본정책의 «공용화»).

★**토지비도 같은 축**: 공시지가×1.1 대신 **실거래 median** 을 쓰되, 없으면 공시지가로
내려가고 **그 사실을 라벨에 남긴다**. B3 의 `1_500_000` 폴백은 **제거하고 `None`** 으로
(「모름」이 값을 입지 않게 — 볼트 §미조회는 관측이 아니다).

### P1 — `market_precision` 을 수지에 배선 (요구 ①②)

★**이미 있다**(A7): 비교사례 명시 · **시점보정**(R-ONE 실계수, 없으면 `UNKNOWN`+미보정,
**외삽 금지**) · 흡수율. 지금은 **분양 모듈만** 쓴다.

**처방**: 수지 응답에 `market_precision` 을 실어 **표준가의 근거를 화면까지** 올린다.
→ 요구 ①(분양사례조사·표준가)의 **대부분이 여기서 충족**된다.

★**「금액÷면적」 금지**(§0 기각 ①)를 이 배선에서 지킨다 — `_trade_per_pyeong` 의 기존 산식을
그대로 쓰고 **새로 나누지 않는다**.

### P2 — **없는 축만** 새로 만든다: 건축연한 가중치 (요구 ②)

A5 로 **0건 확증**(대조군 포함). 이것만이 진짜 신규다.

- 축: 준공연도 → 경과연수 → **보정계수**. 비교사례를 **신축 기준으로 환산**한다.
- ★**계수의 출처를 만들어 내지 않는다.** 근거 후보: ①`desk_appraisal_service._building_value`
  의 기존 감가 로직(이미 있다 — 형제를 먼저 본다) ②R-ONE 연식별 지수.
  **어느 쪽도 확보 못 하면 `UNKNOWN` + 미보정**으로 두고 계수를 지어내지 않는다.
- 반영 지점: `market_precision.ComparableSet` 의 사례별 보정(시점보정과 **같은 자리**).

## 3. ★검증하지 못한 것

- **하드코딩 지역테이블과 실거래의 괴리 크기를 재지 않았다.** P0 이 «얼마나» 개선인지 모른다.
  → 착수 전 **동일 현장 N개로 두 경로를 나란히 돌려** 차이를 먼저 재야 한다.
- **`_trade_per_pyeong` 의 표본 충분성 미측정.** 동 레벨 `n` 이 몇일 때 median 이 안정되는지
  모른다. **n=1 도 median 을 낸다** — 표본 하한 없이 배선하면 이번엔 **다른 종류의 날조**가 된다.
- **건축연한 계수의 출처가 아직 없다.** P2 는 «출처를 찾으면» 조건부다.
- **`market_precision` 이 수지 입력 형태와 맞는지 미확인**(분양 도메인 계약으로 만들어졌다).
- **부담금 수동 보충의 회계적 타당성 미검토** — 사용자가 넣은 값이 «조사됨» 으로 승격되면
  안 된다(3상태 게이트의 뜻이 무너진다).
- **소방 단가**: `FIRE_PROTECTION_ITEM` 이 **단가 미확보로 보류** 상태. P3 의 직접입력이
  그 자리를 덮을 수 있으나 **법정 분리도급 표기**를 함께 해야 한다.
- **성장루프 도메인 축 신설의 비용** 미측정.

## 4. 되돌리기

P0~P3 이 **각각 독립 PR**. P0 은 시드 함수 한 곳의 분기 추가라 되돌리기 1커밋.

| P2 | **두 모집단**: 연식 있는 사례 → 보정됨 ↔ 연식 **없는** 사례 → `UNKNOWN` + **미보정**(계수 날조 금지) | 방향이 있는 결함엔 방향 있는 단언 |
| P3 | override 가 **실제로 계산에 실린다**(값이 결과를 바꾸는지 — 키 존재 아님) + **재실행 후에도 남는다**(provenance) + ★**음성 대조군**: 자동값은 갱신된다 | 「필드만 있고 소비처 0」이 이 저장소의 반복 결함 |
| P3 | 부담금 수동 보충이 **`surveyed` 를 승격시키지 않는다** | 3상태 게이트의 뜻을 지킨다 |
| 전단계 | **표본 하한**: `n` 이 하한 미만이면 실거래를 쓰지 않고 그 사실을 라벨에 남긴다 | «n=1 median» 이 새 날조가 되는 것을 막는다 |
