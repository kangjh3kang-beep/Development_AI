## 2. 정보 표시 문법 (디자인 규칙 — DESIGN.md Part B "Nexus Geo-Intelligence" 준수)

**G1. 줌 롤업(Zoom-level rollup)** — 호갱노노/밸류맵 문법.
- z≥17(필지): 필지 폴리곤 + **컴팩트 칩 라벨**(지번 축약 "56-16" + 1개 보조필드)
- z 14~16(블록): 선택군 집계 칩 1개("12필지 · 12,079㎡ · 3,653.9평") — 개별 라벨 숨김
- z≤13(지역): 프로젝트 핀만. *주소 전문(全文) 라벨은 어떤 줌에서도 지도 위에 띄우지 않는다.*

**G2. 라벨 조합 규칙(Regrid 패턴)** — 과밀의 구조적 방지.
- 보조필드는 **1개만** 선택 토글: 면적(평) | 용도지역 | 실효FAR | 공시지가 | 없음
- 기본값: 없음(지번만). 선택 필지는 채움색+테두리로 이미 구분되므로 라벨 최소주의.
- 구현: 칩은 `L.marker + divIcon`(pane=labelPane 재사용), collision 회피는 줌 롤업으로 해결.

**G3. 상세는 지도 밖 적층 패널로(디스코 패턴)** — 지도 위엔 식별자, 판단 정보는
우측 사이드패널(360~500px, 3열 셸 B3.1)에. 호버=경량 툴팁(지번·면적·용도지역 3줄).

**G4. 색상 = 데이터 토큰** — 용도지역 폴리곤은 카카오 지적편집도 표준 색상 준수(사용자
학습 관성), 분석 히트맵은 tokens.css 시퀀셜 스케일(primary 계열 5단), 리스크는
status-success/warning/error 3색 신호등. 임의 hex 금지.

**G5. 라벨·텍스트 가림 금지** — 베이스맵 지명은 labelPane(z450)으로 폴리곤 위에(기존
Hybrid + PR#347의 Base/gray 확장). 우리 칩 라벨은 그 위(z460 신설 chipPane).

### WS-D [P1] 분석 오버레이 레이어 세트 — D5, 독보 기능 1호

   "지을 수 있는 만큼 못 지은 땅" 발굴. calc_effective_far(7계층 min) + 건축물대장 연면적.
   뷰포트 내 필지 일괄 산출은 배치 엔드포인트 신설(캐시 필수 — 분석캐시 규약 재사용).
2. 노후도: 건축물대장 사용승인일 → 연한 5단 색상(부동산플래닛 대표기능 이식).
3. 공시지가: 필지 코로플레스(디스코 보유).
4. **규제 리스크 신호등(독보)**: 개발행위허가 필요·경사도/임야·군사/문화재 영향권을

### WS-E [P2] 구역 그리기 + 다필지 장바구니(합필 What-if) — 독보 기능 2호

2. **합필 장바구니**: 필지를 담고 뺄 때마다 통합면적·평균 실효FAR·개략수지(NPV·수익률)

   "이 필지를 추가하면 사업성이 얼마나 좋아지는가"를 지도에서 즉답(전 세계 부재 기능).
3. (P3) 합필 추천: 인접 저이용 필지 자동 제안(LightBox assemblage의 개발사 버전).
