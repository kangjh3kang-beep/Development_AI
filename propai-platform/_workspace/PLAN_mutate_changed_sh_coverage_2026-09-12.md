## §3 ★검증하지 못한 것

1. **`.sh` 변이가 「설명 불가 생존」을 실제로 몇 건 드러내는가** — 미측정. 이 PR 은 **모집단을 넣는 것**까지이고,
   드러난 생존을 봉합하는 것은 **별건**이다(그 봉합을 이 PR 에 끌어들이면 범위가 두 개가 된다).
2. **루트 `scripts/` 5건**(`coord.sh` · `mutate_manual.sh` 등)은 **여전히 배제된 채로 둔다.** 그 게이트의 사유
   (*"도구 자신은 이 테스트들의 대상이 아니다(오탐)"*)가 지금도 참인지 **미측정** — 이유는 **장치 부재가 아니라
   「안 쟀음」**이다. 이 PR 의 범위를 넘으므로 부채로 **초록 안에 드러낸다**(`it.todo` 대응 = `xfail`).
3. **`.sh` 에 heredoc 내부 줄이 변이 대상으로 들어오는가** — `.py` 는 `_docstring_line_nos` 가 걸러 주지만

   구문상 유효하다). 미측정 · 부채로 기록.

## §5 잠금 — 이 변경을 지키는 검사

| 잠글 것 | 검사 |
|---|---|
| `.sh` 가 모집단에 **실제로 들어온다** | `_changed_files` 에 `.sh` 를 태워 반환에 포함되는지 + **대조군**(`.md` 는 여전히 제외) |
| 셸 조건 변이가 **발화한다** | `if [ -z "$X" ]; then` 에서 `if false; then` 변이가 생성되는지 + 대조군(파이썬 `if x:` 은 셸 규칙으로 안 잡힘) |
| `exit N` 변이가 **발화하고 `exit 0` 은 안 건드린다** | 두 모집단(`exit 7` → 생성 / `exit 0` → 미생성) |
| **구문 게이트가 실재한다** | 구문을 깨는 변이를 주입해 **CAUGHT 로 세어지지 않음**을 단언(양방향: 구문 정상 변이는 정상 판정) |
| 탐색이 **참조 파생**이다 | `safe-deploy.sh` 를 주면 그 basename 을 담은 테스트가 나오는지 + **공허 방지 선단언**(결과가 비면 조회기 사망) |
| 게이트를 **`bash -n`** 으로 쓴다(`sh -n` 아님) | P5 의 6파일 중 하나를 실제로 태워 `sh -n` 이면 거짓 실패, `bash -n` 이면 통과임을 단언 |
