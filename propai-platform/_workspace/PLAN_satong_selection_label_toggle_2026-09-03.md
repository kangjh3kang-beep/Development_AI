# 계획 — 사통맵 「선택 필지」 토글이 **배선돼 있지 않다** (2026-09-03)

★사용자 신고: 206필지 선택 시 지번 라벨이 지도를 덮어 **가독성이 떨어진다.**
  요구: **기본은 표시하되 끌 수 있게.**
★조사 결과 요구된 UI 는 **이미 있다.** 문제는 *"만드는 것"* 이 아니라 *"배선하는 것"* 이다.

## 0. 옵시디언 조회 결과 (§계획게이트 0)

| 찾을 것 | 결과 |
|---|---|
| 이미 기각된 접근 | **없음**(이 주제로 기각 기록 0건) |
| 같은 클래스의 앞선 결함 | **있음** — `2026-09-02_작동하지_않는_조작_수단을_만들_뻔했다`(동료 세션): *"관리자에게 「저장됨」 초록만 뜨고 아무것도 안 바뀌는 버튼을 줬다"*. **이 건은 그 형태의 실재판**이다 |
| 미결·부채 | 사통맵 라벨 LOD 롤업은 이미 있음(`selectionRollup`) — 줌아웃에서만 동작 |
| 이전 판단의 근거 | 코드 주석이 *"줌 롤업(U-라벨 파일업)"* 을 적어 뒀다 — **줌아웃은 대비했는데 줌인 다필지는 안 했다** |

## 1. 전제 표 — 확인 방법과 **실제 측정값**

| # | 전제 | 확인 방법 | **결과(실측)** |
|---|---|---|---|
| P1 | 「선택 필지」 토글 UI 가 있나 | `SatongMapShell.tsx` | **있다** `{id:"selected", label:"선택 필지", mapEffect:true}` (337줄) |
| P2 | 기본이 켜져 있나 | `defaultControlsByLayer()` | **켜짐** — `cadastre: ["boundary","selected"]` |
| P3 | 지도가 그 컨트롤을 읽나 | `SatongMultiMap` 전수 | ★**0건** |
| P4 | ★조회기가 살아 있나(대조군) | 같은 파일의 다른 컨트롤 | `boundary`·`building-age`·`land-use`·`unit-price` **읽음** |
| P5 | 라벨을 그리는 곳 | `SatongMultiMap` 2450~2510 | 이펙트 deps = `[mapReady, overlayFeatures, selectionRollup]` — **토글 없음** |
| P6 | 줌아웃 대비는 있나 | 같은 이펙트 | **있다** — `selectionRollup` 이 다필지를 집계 칩 1개로 롤업 |
| P7 | 겹치는 열린 PR 이 있나 | 열린 PR 전수 | **0건** |
| P8 | ★게이트를 걸면 **다른 화면이 깨지나** | `<SatongMultiMap` 프로덕션 호출부 전수(6) | ★**3곳이 깨질 뻔했다** — `NearbyTransactionsMap`(layerState 미전달) · `LandScheduleClient`·`GlobalAddressSearch`(`controlsByLayer: {}`) |
| P9 | 나머지 호출부의 컨트롤 어휘 | 소스 | ★**두 벌** — 툴바는 `selected`, `ZoningSignalMap`·`ParcelBoundaryMap` 은 `selected-parcel` |
| P10 | 헬퍼가 레이어 활성을 요구하나 | `hasSatongLayerControl` 본문 | **아니다** — `controlsByLayer` 만 읽는다(레이어 OFF 여도 컨트롤 유효) |
| P11 | 레이어를 끄면 컨트롤이 지워지나 | `controlsByLayer` 갱신 전수(3곳) | **아니다** — 지우는 코드 0건 |
| P12 | jsdom 에서 라벨 이펙트가 도나 | 스모크 테스트 주석·`window.L` | **안 돈다** — CDN 미로드로 `mapReady` 영영 false |

★**P8 이 처방을 바꿨다.** `hasSatongLayerControl(state,"cadastre","selected")` **한 줄**로
게이트를 걸었으면 **3/6 화면에서 라벨이 조작 수단 없이 사라졌다.** 그래서 규칙을 바꿨다:

> **컨트롤을 「선언한」 화면만 그 선언대로 판정한다. 선언이 없으면 = 끄는 수단이 없으면 표시한다.**

★**P3 + P4 가 핵심이다**: 조회기가 살아 있는데 0건 = **진짜 미배선**이다.

## 2. 변경 내용과 **회귀가 아닌 근거**

선택필지 **라벨** 렌더를 `satongSelectionLabelsVisible(layerState)` 로 게이트한다.

★**주의 — 채택되지 않은 설계**: 처음에는 `hasSatongLayerControl(layerState, "cadastre", "selected")`
**한 줄**이었다. P8 이 그것을 기각했다(3/6 화면이 깨진다). 기각된 설계를 여기 남겨 두는 이유는
§1 만 읽고 §2 를 읽는 사람이 **옛 설계를 사실로 받는 것**을 막기 위해서다(리뷰 m-5 지적).

- **회귀 아님**: 기본이 ON(P2)이므로 **아무것도 안 바꾸면 지금과 같다.**
- 폴리곤/하이라이트는 **레이어 단위 게이트 그대로** 둔다(라벨만 끈다 — 가독성 문제의 원인).
- 기존 롤업(P6)과 **독립**이다: 토글 OFF 면 롤업 여부와 무관하게 라벨이 없다.

## 3. ★검증하지 못한 것

- **브라우저에서 눈으로 확인하지 못했다.** ★단, 최초 작성 시 적었던 *"이 워크트리에
  `node_modules` 가 없어 vitest 를 못 돌린다"* 는 **더 이상 참이 아니다**(설치했다 · 실측
  `27 passed`). 리뷰어가 이 낡은 라벨을 지적했다 — **적어 둔 한계는 재측정 없이 승계된다.**
- `cadastre` 의 **`boundary`·`neighbors` 컨트롤도 미배선**이다(P3 과 같은 조사에서 확인).
  **이번 범위 밖**으로 둔다 — 사용자 요구가 라벨이고, 한 번에 셋을 바꾸면 회귀 판정이 어렵다.
  ★**부채로 남긴다고 여기 적는다**(안 적으면 다음 사람이 배선된 줄 안다).
- 라벨을 끈 상태에서 **다른 기능(클릭 선택·포커스)이 영향받는지** 안 쟀다.
- ★★**정정(적대 리뷰 후)**: 이 항목은 **두 겹으로 틀렸다.**
  ① *"이펙트가 jsdom 에서 안 돈다"* 를 **잠글 수 없는 이유**로 적었는데, 형제
     `lib/satong-layout-overlay.ts` 가 **같은 문제를 이미 풀어 두고 그 처방을 주석에
     명문으로** 적고 있었다(L 주입 순수 모듈 + `!mapReady` 조기반환을 일부러 두지 않음).
     **한계가 아니라 내가 형제를 안 본 것이었다**(§29).
  ② *"뒤에 두어야 끌 때 낡은 라벨이 철거된다"* 를 **측정 없이** 주석·계획서·PR **세 곳에
     사실로** 실었다. 리뷰가 반증 가능성을 지적했다(React 는 deps 변경 시 이전 클린업을
     먼저 돌린다). → 추출로 **순서 의존 자체를 없앴다**(정리를 계획과 무관하게 항상 먼저).
     그 문장은 지웠다. **잠글 수 없는 주장은 지우는 것이 가설로 남기는 것보다 낫다.**
- ★**두 어휘 통합**(`selected` ↔ `selected-parcel`)은 하지 않았다. 닫힌 집합으로 **세 번째**만
  막았다(P9). 통합은 별건 — 이 PR 에서 하면 회귀 판정이 섞인다.
- ★**토글이 영속하지 않는다**(리뷰 m-7). `layerControls` 는 `useState` 뿐이라 새로고침·재진입마다
  다시 꺼야 한다. 206필지 워크플로에서는 체감 해결도를 깎는다. **하지 않기로 한 것**이며,
  이유는 영속 저장소 선택(localStorage vs 서버 store)이 이 PR 의 범위를 넘고 다른 레이어
  컨트롤 전체와 함께 결정해야 하기 때문이다. **별건으로 올린다.**
- ★**`NearbyTransactionsMap` 회귀 표기가 과장이었다**(리뷰 m-6). 그 호출부는 `selectedParcels`
  를 전달하지 않고 `readOnly` 라 `overlayFeatures` 가 항상 비어 있다 — 순진한 게이트로도
  **사라질 것이 없었다.** 실질 위험 호출부는 5가 아니라 **4**다.

## 4. 되돌리기 경로

게이트 한 줄을 지우면 종전 동작(항상 표시)으로 돌아간다. 읽기 경로·상태 구조 무변경.

## 5. 잠금

| 축 | 락 |
|---|---|
| **효과** | 토글 OFF → 라벨이 **실제로 없다** / ON → **있다**(두 모집단) |
| **기본값** | `defaultControlsByLayer()` 에 `selected` 가 있다 = **끄지 않으면 보인다** |
| **배선** | 이펙트가 그 컨트롤을 읽는다(이름이 아니라 **동작**으로) |
| ★**미배선 감지** | `cadastre` 컨트롤 중 **선언됐지만 안 읽히는 것**을 세어, 늘면 실패 |

★마지막 축이 중요하다 — 이 결함이 **또 생기는 것**을 막는다(선언만 하고 배선 안 하는 형태).
