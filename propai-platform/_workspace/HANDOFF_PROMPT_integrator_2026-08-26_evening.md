## 1. ★이번 세션이 배운 것 중 **당신이 바로 밟을 것**

### 계기판 프로브
- 활성 스택은 **caddy 가 안다.** `docker ps | head -1` 은 **유휴 스택**을 집는다
  (오늘 활성 포트가 8001→8000→8001 **두 번 뒤집혔다**).
  ```bash
  PORTS=$(grep -vE '^[[:space:]]*#' ~/caddy/Caddyfile | grep -oE 'reverse_proxy[[:space:]]+localhost:80[0-9]+' | grep -oE '80[0-9]+' | sort -u)
  [ "$(printf %s "$PORTS" | grep -c .)" -eq 1 ] || exit 3     # ★빈 값이면 반드시 죽어라
  ```
- DB 조회는 **앱 엔진을 임포트**하라: `from app.core.database import engine`.
  직접 `create_async_engine` 하면 pgbouncer 에서 `DuplicatePreparedStatementError` 로 죽는다.
- ★★**`SET default_transaction_read_only` 을 걸지 마라.** 세션 설정이 트랜잭션 풀의
  **남의 커넥션으로 샌다** — 오늘 서브에이전트가 그것으로 **12분간 프로덕션 쓰기를 막았다.**
- ★★**돌아가는 프로덕션 컨테이너에 파일을 넣지 마라.** 오늘 내가 테스트를 돌리려다
  `docker cp` 로 **라우터 소스를 덮어썼다**(원복·확증 완료). 필요하면 **같은 이미지로
  일회용 컨테이너**를 띄우거나, 못 돌리면 **CI 에 맡기고 "로컬 미검증"이라 적어라.**

### 배포 지표
- **배포 전 0 확인**이 오늘만 후보 6종을 걸렀다. 후보마다 **원문 라인을 열어라.**
- **export 함수명은 하한 지표**다 — 실측 생존율 79%(14중11) / 33%(3중1).
  `>0` 이면 배포됨은 참, **`0` 이면 미배포는 거짓**(판정 불가). 배포 전에 그 사실을 적어 두면 오보를 막는다.
- **모듈 지역변수(`let x`)는 확실히 소멸**한다. **TS 타입 주석의 키도 컴파일 시 지워진다**
  (`balanced_absent` 가 그랬다). **키인 것과 화면이 읽는 것은 다르다.**
- **신규 UI 문자열이 있으면 그것이 1순위**다.
- ★공백 포함 값을 `for` 루프로 순회하지 마라(쉘이 쪼갠다). `while IFS= read -r` + `grep -F --`.

### 큐 운영
- strict + auto-merge 라 **한 번에 하나만** `update-branch`. 순서는 **계산**한다:
  ```bash
  gh pr view N --json files --jq '.files[].path' \
    | grep -E '^propai-platform/apps/(web|api)/' \
    | grep -vcE '(^|/)(tests?|e2e)/|\.test\.|\.spec\.|__tests__'
  ```
  ① 사용자에게 닿는 실결함(런타임>0) ①-b **운영자가 읽는 값이 거짓인 것**(런타임 0이어도 여기)
  ② 라이브 응답 불변 ③ 순수 test·docs
- ★**"한 번에 하나"는 슬롯을 넘기는 사람이 있어야 돈다.** 오늘 10건 전부 BEHIND 인 채
  아무도 안 미는 교착이 왔다. **순서를 제안한 사람이 명시적으로 넘겨라.**
- 내 PR 은 **auto-merge 를 끄는 것이 구조적 양보**다.
