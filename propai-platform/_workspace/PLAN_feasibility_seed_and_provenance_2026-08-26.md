## 2. 고친 것

**B1 — 부지 시드 공용화** (`lib/feasibility-seed.ts` 신설)
세 소비처(오케스트레이션 · 폼 자동시드 · 폼 수동버튼)가 **같은 산출처**를 쓴다.
★**정상 입력에서는 동작이 같다. 「안 바꿨다」는 거짓이었다**(적대 리뷰가 360조합 차분으로 반증).
차이는 **퇴화 입력 3종**뿐이고 전부 더 보수적이다 — 주소 선행공백(`trim()` **신설**) ·
음수/`Infinity`(`Number()`+`>0` **신설**) · 공백뿐인 주소. **`trim()`·`Number()` 는 형제에 없던
새 규칙**이다. 회귀는 아니지만 *"그대로 옮겼다"* 고 적으면 후임이 재검증하지 않고 신뢰한다.

**B2 — 수지 수동값 보호** (`ProvenanceModule` 편입 + **생산자 배선**)
★**초판은 가드만 놓고 생산자를 안 놓았다** — 적대 리뷰가 차단 사유로 짚었다. 프로덕션 호출부
**7곳 중 `meta` 를 주는 곳이 0곳**이라 `manualFields.feasibility` 를 **아무도 쓰지 않았고**,
테스트가 초록이었던 것은 **테스트가 스스로 `{source:"user"}` 를 불렀기 때문**이다
(*"정의만 하고 소비처 0"*). → 실제 사용자 편집 표면(`PipelineResultDetail` 의 `총사업비`·`총수입`
`editable:true`)을 `STORE_FIELD_MAP` + `persistFieldToStore` 에 배선하고, **손수 이항 분기**
(`siteAnalysis ? … : costData`)를 **파생 표**로 바꿨다(세 번째 모듈이 조용히 오독되던 자리).
`updateFeasibilityData(data, meta?)` 로 형제(`updateCostData`)와 시그니처를 맞췄다.
★가드 형태는 **베끼지 않았다** — `cost` 는 full replace 라 flagged 키를 이전값으로 되돌리지만,
여기는 **merge patch** 라 들어온 `data` 안의 flagged 키만 되돌린다.
★`equityIsManual` 기존 계약은 **그대로 살아 있다**(무회귀 케이스로 잠갔다).

## 4. ★검증하지 못한 것

1. **라이브 종단 미실시** — 실제 파이프라인 재실행으로 사용자 값이 남는지는 배포 후에도 **미측정**.
   자동 테스트가 그 축을 덮지만 **라이브는 아니다**.
2. **다필지 공시지가** — 면적은 합산인데 단가는 **대표 1필지**(`officialPrices[0]`)다.
   **이 커밋이 만든 것이 아니라 옮겨 온 것**이고, 값 차이는 **미측정**이다 → `it.todo` 로 남겼다.
3. **`sido_name` 파싱** — 주소 첫 토큰 규칙을 그대로 옮겼다. `세종특별자치시` 처럼 시군구가 없는
   경우의 정합은 **미측정**(종전과 동일하므로 회귀는 아니다).
4. **B3~B6 는 범위 밖**(blob LWW · 의존성 3벌 · 부담금 지역화 · 검산층). 별건이다.
5. **부분 setter 3개가 가드를 우회한다** — `setRecommendedDevType`·`setSalesPricePerPyeong`·
   `setEquityRatioPct` 는 `feasibilityData` 를 직접 덮고 가드를 안 탄다. 셋 다 현재는 자동/파생
   경로라 무해하지만, 사용자 편집이 그 필드로 확장되면 같은 결함이 살아난다. **미수정.**
6. ★**파생 필드 정합 붕괴** — `totalCostWon` 만 user 로 잠긴 상태에서 자동 재실행이 오면
   `profitRatePct`·`grade` 는 **자동 총사업비 기준**으로 갱신돼 화면에 서로 다른 기준의 값이
   나란히 뜬다. 필드 단위 provenance 와 파생 관계의 궁합 문제다. **미해결 · 설계 판단 필요.**
7. **`provenanceGuarded` 라벨의 원래 의미 미측정** — 그 플래그가 **노드 산출**에 걸린 것인지
   **입력 슬롯**에 걸린 것인지 재보지 않았다. 그래서 **값은 보수적으로 유지**하고 사유만 고쳤다.
8. **생산자 배선 락은 소스 락이다** — `PipelineResultDetail` 을 **렌더까지 태우지 않았다**.
