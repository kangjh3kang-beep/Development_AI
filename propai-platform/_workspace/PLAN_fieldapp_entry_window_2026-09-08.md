사용자 신고(원문): *"메인플랫폼에서 분양앱을 누르면 새창이 아닌 같은 창에서 이동하면서
메인플랫폼 이용자는 다시 메인플랫폼으로 이동하지못하는 번거러움이 발생하고 있어"*
그리고: *"새창앱에서는 메인플랫폼으로 이동하지 않아도 되지만"*

복귀로는 **그 원인을 못 고치는 모집단**(같은 탭 진입)에만 필요하다.

## 2. 변경 내용과 **회귀가 아닌 근거**

### C1. 창 열기 판정을 **공용 함수로 추출** (`lib/field-app-launch.ts`, 신설)
`FieldAppAffordance.tsx:80-85` 에 인라인돼 있던 팝업 features·차단 폴백을 **한 함수**로 뺀다.
어포던스도 그것을 쓰도록 고친다.
- **회귀 아님**: 동작은 동일(같은 features 문자열·같은 폴백 순서). 락 C1-a 가 두 소비처를
  **파생형**으로 잠가 형제가 갈리지 않게 한다(저장소가 반복해 데인 «형제마다 가드가 갈린다»).

### C2. 진입을 새 창으로 (`FieldAppLaunchLink.tsx` 신설 + 소비처 2곳)
`<a href>` 를 **유지**하고 `onClick` 에서 가로챈다 — 가운데클릭·새탭열기·JS 실패 시 **기존 동작 보존**.
- 소비처①: `SalesSiteList.tsx:102`
- 소비처②: 레지스트리에 `launch: "app-window"` 를 **SSOT 로 선언**하고
  `RouteDef → RegistryNavNode → NavNode → SidebarNav` 로 흘린다(경로 문자열 특수처리 금지 — 목록형 회피).
- **회귀 아님**: 팝업이 차단되면 `_blank` → 그것도 막히면 **같은 창 이동**으로 떨어진다.
  즉 최악의 경우가 **오늘의 동작**이다.

### C3. 복귀로는 **같은 탭 모집단에만** (`PlatformReturnLink.tsx` 신설 → `SiteListClient`)
`useFieldAppShell` 의 두 축으로 가른다.

| 모집단 | 복귀로 | 근거 |
|---|---|---|
| 설치본(`standalone`) | **안 보임** | 사용자 명시(*"새창앱에서는 이동하지 않아도 되지만"*) + 스코프 이탈 회피 |
| 별도 창(`inSeparateWindow`) | **안 보임** | 같음. 그리고 P5 — 그 창에서 나가면 판별자가 틀린 답을 낸다 |
| 일반 탭 | **보임** | 원인(C2)이 못 닿는 모집단. 북마크·직접 URL·팝업 차단 진입 |

- **회귀 아님**: 오늘 아무 데도 없던 것을 **한 모집단에만** 추가한다. 없어지는 것이 없다.
- 배치는 **깊이 0(목록)** — P3 이 짚은 막다른 골목이 거기다.

## 3. ★검증하지 못한 것

- **설치본에서 스코프 밖 이동 시 브라우저 실제 동작** — **장치 부재**(실기기 iOS/Android 없음).
  명세상 앱 프레임이 아니라 브라우저 UI 로 열린다고 **추론**하나 실측 0건.
  ⇒ 그래서 설치본에서는 복귀로를 **아예 안 그린다**(모르는 동작에 의존하지 않는다).
- **WebKit·Firefox 의 `window.name` 유지** — 장치 부재. 잰 것은 **크로미움뿐**이다.
- **별도 창에서 `display-mode: standalone` 이 매치되는지** — **미착수**.
  `field-app-shell.ts:22-30` 은 두 축이 「배타적 커버」라고 단정하지만 이 저장소에서 미검증이다.
- **팝업 차단 환경의 실제 분포** — 미측정. 폴백은 만들었으나 **얼마나 자주 타는지 모른다.**
- **현장앱 실사용자 수** — P8 이 말하는 것은 「API 트래픽 0」이지 「사용자 0」이 아니다.
  창(5일) **밖**은 미측정.

## 4. 되돌리기

세 커밋이 독립이다. `git revert` 로 **C3 → C2 → C1** 순서로 되돌릴 수 있다.
- C3 만 되돌리면: 복귀로가 사라지고 C2(새 창)는 남는다 — **사용자 신고는 여전히 해소** 상태.
- C2 만 되돌리면: 같은 창 이동으로 복귀하지만 C3 복귀로가 남아 **오늘보다 낫다**.
- ⇒ 어느 하나만 되돌려도 **오늘보다 나쁜 상태가 없다.**
