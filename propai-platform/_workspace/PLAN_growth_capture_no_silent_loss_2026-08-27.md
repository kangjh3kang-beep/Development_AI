## 3. ★검증하지 못한 것

1. **라이브 미확인** — `/growth/effectors` 는 **배포 전**이다(404 · 대조군 200).
   실제 유실 수치는 **배포 후에야** 볼 수 있다.
2. **과거 유실량 미상** — 세는 것이 없었으므로 **영원히 알 수 없다**. 이 PR 은 앞으로만 잰다.
3. **`_STATS` 는 프로세스 로컬** — 재시작하면 0으로 돌아가고, 다중 워커면 워커별로 다르다.
   ★따라서 이 수치는 **하한**이다(전체 유실 ≥ 보이는 값). 그 사실을 코드에 적었다.
4. **90일 롤업/prune 미구현** — 이 PR 범위 밖. 나중에 구현되면 `never_fired` 판정이
   조용히 뒤집힌다(#915·#917 의 `TELEMETRY_SINCE` 가 그것을 완화하지만 없애지는 못한다).
5. **부하 시험 미실행** — 천장 100건/초를 실제 트래픽으로 넘겨 보지 않았다(산술만).

### ★독립 적대 리뷰(REVISE)가 §3 의 누락으로 지목한 것 — 추가 (2026-08-27)

리뷰가 *"§3 의 다섯은 정직한데 **빠진 것이 있다**"* 고 했고 맞다. 여기 적는다:

6. **동시성** — `_consecutive_failures` 는 **모듈 전역**이라 flusher 가 둘이면
   ①상한이 **영원히 발화하지 않고**(다른 flusher 의 성공이 계속 리셋) ②`_drain`+되돌리기가
   원자적이지 않아 **FIFO 가 역전**된다(리뷰 실측: `e0..e5` → `e3,e4,e5,e0,e1,e2`).
   ★**정상 상태에서는 도달 불가**다 — `Dockerfile.oracle` 이 `uvicorn --workers 1` 이고
   flusher 는 단일 asyncio 태스크다(리뷰가 확인). **부채로 기록**한다:
     · 종료 창(취소 미대기 + 마지막 flush 중첩)에서 잠깐 둘이 될 수 있다
     · 큐를 Redis 공유로 옮기면(코드가 그것을 예고한다) **즉시 실재 결함**이 된다
   → 그때는 상한을 **배치 정체성**(첫 행 `event_id` 해시 등)에 걸어야 한다.

7. **되돌리기는 「가장 새것」을 밀어낸다** — `appendleft` 라 오른쪽(최신)이 나간다.
   정상 유입 경로와 **반대**다. 계수는 같은 칸이지만 뜻이 다르다(코드에 적었다).

8. **`requeued` 는 행이 아니라 연산을 센다** — 500행을 12회 재시도하면 `6000` 이 된다.
   화면의 「되돌림 200건」을 **200개 행**으로 읽으면 틀린다. ★미해결 부채.

9. **arq 워커의 큐는 flusher 가 없다** — 워커에 flush 루프가 **0건**(대조군: API 쪽 실재).
   그 프로세스에서 `record_event` 가 불리면 **100% 유실**이고 `capture_status()` 는
   구조적으로 그것을 못 본다(프로세스 로컬).
   ★**재측정 결과 현재는 도달 불가로 보인다**: 워커가 임포트하는 **19개 `app.*` 모듈 중
   `record_event`/`record_fallback` 호출 0건**.
   ★**단 전이 임포트는 안 쟀다** — 한 단계 직접 임포트만 훑었다. 그래서 *"없다"* 가 아니라
   **"직접 경로에는 없다"** 가 정확한 표현이다.

10. **`mutate_changed.py` 「47종 생존 0」은 휘발성 값이다** — 그 도구의 기본 base 가
    `origin/main` 이라 **브랜치가 뒤처지면 남의 PR 파일까지 변이한다**(리뷰 재실행: 60종·생존 6,
    그중 이 PR 파일은 1줄뿐). ★그 수치는 **기준 커밋과 함께**여야 의미가 있다:
    측정 시점 base = `26c3e00e`, 대상 = `capture_service.py`·`effector_firing.py`.
    그리고 **그 도구의 생존 0 은 「모듈이 잠겼다」는 뜻이 아니다** — 카탈로그(줄삭제·문자열변경)가
    **상수값·파일간 결합 변이를 만들지 못한다**. 실제로 리뷰의 M1·M2·M3 이 거기서 나왔다.
