## 2. 변경 내용

`footer_callback` 이 `register_font()` 결과를 쓴다. **한 줄**이고, 폴백 로직을 이중화하지 않는다
(그 함수가 이미 갖고 있다). 페이지마다가 아니라 **콜백 생성 시 1회** 해석한다.

**회귀가 아닌 근거**: 라틴·숫자도 CID 명조로 그려지지만 `HYSMyeongJo-Medium` 은 ASCII 를 포함한다.
꼬리글은 크기 7.5pt 의 보조 텍스트라 자간 차이가 레이아웃을 흔들지 않는다(P7 의 오버플로 0 이 이를 지지).

## 3. ★검증하지 못한 것

1. **표 줄바꿈·오버플로는 표본 1건만** 쟀다(P7). 다필지·장문 이름 보고서는 미측정.
2. **픽셀 렌더**를 보지 않았다. 텍스트 추출로 판정했다 — 글리프가 실제로 그려지는지는
   추출 성공으로 **추정**한 것이다(반증 조건: 추출은 되는데 화면엔 안 보이는 경우).
3. **PPTX/DOCX** 의 한글 폰트는 이 PR 범위 밖이다(`FONT_KR_GOTHIC` = 뷰어 로컬폰트 의존).
4. 13개 보고서 중 **실제로 열어 본 것은 realtx 1종**이다. 나머지는 같은 공용 헬퍼를 쓴다는
   **소스 근거**로 전파를 주장한다 — 각각을 렌더해 보지는 않았다.
