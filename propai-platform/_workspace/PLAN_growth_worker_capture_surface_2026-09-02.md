## 2. 변경 내용과 **회귀가 아닌 근거**

워커의 flush 루프가 주기적으로 자기 `capture_status()` 를 `platform_settings` 에 **발행**한다.

- **새 표면을 만들지 않는다** — 기존 `set_setting` → `active_flags` 통로를 **그대로 탄다**(§7 형식 이식).
- **읽기 경로 무변경** — `/heal-log` 는 코드 변경 없이 그 행을 이미 그린다(P4·P5 로 확인).
- 발행 실패는 **삼키고 로그만** — 관측이 배수를 죽이면 안 된다(기존 flush 루프와 같은 규율).

## 3. ★검증하지 못한 것

- **프로덕션 워커가 실제로 초당 몇 건을 쌓는지** — 여전히 **미측정**. 이 표면이 그것을 재는 도구다.
- **워커가 이 발행을 실제로 하는지**는 **배포 후에만** 확인된다(로컬은 arq 런타임이 없다).
  → 배포 판정 프로브를 §5 에 적는다.
- `analysis_coverage` 부채 · 프론트 렌더 — **범위 밖**(3중 경합).

## 4. 되돌리기 경로

발행 호출 한 곳을 지우면 끝난다(읽기 경로를 안 건드렸으므로 잔재 없음).
★**정정(2026-09-02 · 독립 적대 렌즈)**: 종전 이 자리에 *"행은 남지만 … **모집단 ②로 스스로 드러난다**"* 라고 적었는데 **거짓이었다.** ②는 **깊이 N**인데 되돌리면 **깊이 0** 이다.
게다가 그때는 `at` 이 **화면에 그려지지도 않았다**(아래 §정정 참조).
→ 이제 **TTL 만료로 행이 사라져 ③(관측 없음)으로** 드러난다.

## 5. 잠금 — 이 변경을 지키는 검사

| 축 | 락 |
|---|---|
| **세 모집단 판별** | 깊이 0+최신 / **깊이 N+최신** / **행 부재(TTL 만료)** 가 서로 **다른 답**을 낸다 |
| **배선** | **루프를 돌려** 발행이 나가는지 · 그 프로세스 scope 로 나가는지(양방향) |
| **화면 도달** | 화면의 4키 규칙을 **TSX 에서 파생**해 ①≠② 를 단언 |
| **낡은 스택 구별** | `producer_build_id` 를 싣는다(형제 `analyzer.py` 와 같은 이유) |
| **관측이 배수를 안 늦춘다** | 발행에 상한 · 넘으면 그 주기 관측을 버린다 |

★★**정정(2026-09-02 · 독립 적대 렌즈 REQUEST CHANGES)** — 위 표는 초판에서 **세 줄 다 거짓**이었다:
1. **모집단 ② 정의가 틀렸다.** *"깊이 N + 시각 **정지**"* 는 **관측 불가능한 조합**이다 —
   발행이 멈추면 **깊이도 같이 낡으므로** 「깊이 N」을 볼 수가 없다. 배수가 실패해도
   발행은 계속하므로 진짜 ②는 **깊이 N + 시각 갱신**이다.
2. **③이 원리적으로 발생 불가였다.** TTL 이 없어 행이 한 번 쓰이면 영영 안 사라진다
   (`clear_setting` 은 치유 롤백 전용). → **TTL 이 ③을 만든다.**
3. **③의 락이 항진명제였다.** `s3 = _Store(); assert not s3.rows` — **프로덕션 심볼 참조 0**,
   어떤 변경으로도 실패 불가. ★공허한 단언을 경계하는 문서를 쓰던 **같은 세션에** 내가 썼다.
★**그리고 가장 큰 것**: 판별 필드 `at` 이 payload **15번째**라 화면의 앞 4키 규칙에 **잘려**
  ①과 ②가 **바이트 동일**하게 렌더됐다. **프론트를 「범위 밖」으로 뺐더니 그 전제가
  검증되는 유일한 곳을 뺀 것**이었다.
| **순환 금지** | 발행 경로에 `record_event` 가 **없다**(AST · 음성 대조군 포함) |
| **시각이 값 안에** | `updated_at` 이 아니라 **payload** 에 있다(P6) |
| **배수를 안 죽인다** | 발행이 예외를 던져도 flush 가 계속된다 |

★**모집단은 손으로 고르지 않는다** — `capture_status()` 키에서 **파생**해 계약을 잠근다
(오늘 `#901` 에서 손 목록이 상한이 되어 **HTTP 500 을 놓쳤다**).
