## §3. ★검증하지 못한 것 / 이 PR 이 **고치지 않는 것**

- ★***`cap_rate` 는 고쳐지지 않는다.*** `test_sido_resolution_fail_open.py:1555` 의 strict xfail 이
  선언한 부채(*설정된 표가 소득수익률 항목을 안 담는다 — 라이브 `distinct_ITM_NM=['투자수익률']`,
  2002~2012 폐지 시계열*)는 **그대로 남는다.**
  이 PR 이 하는 일은 ***운영자에게 틀린 것을 넣으라고 말하던 것을 멈추는 것***뿐이다.
- ~~대체 통계표 미측정(이유: 외부 API 쿼터)~~ → ★**그 사유가 거짓이었다**(독립 리뷰 MEDIUM-5):
  `reb_client.py` 에 과금·쿼터 언급 **0건**이고, 같은 저장소가 이 프로브를 **「무인증·무과금」**이라 적는다.
  ⇒ **정직한 라벨은 「아직 안 쟀다」였고, 그래서 쟀다**(2026-09-13 · `GET /land-price/rone-status`):

      keyword="투자수익률" → 후보 **2건**
        「임대동향 투자수익률(분기/연간)(2002년~2012년)_오피스 / _중대형 상가」
      ⇒ 표 이름에 **「소득수익률」이 없다.** 그 표의 항목도 `['투자수익률']` 뿐이다(strict xfail 이 선언).
  ⇒ ***소득수익률을 담은 대체 표는 이 검색 경로에서 안 나온다.*** 라벨을 고쳐도 운영자가 넣을 표가 없다 —
    그래서 이 PR 은 **거짓 지시를 멈추는 것**까지만 하고, 표 확보는 **strict xfail 부채로 존치**한다.
- **운영자 화면 픽셀 미확인**(이유: 이 트리에서 playwright 실행 불가 — 의존성 부분 설치).
