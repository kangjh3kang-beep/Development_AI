## 6. 재생성 금지 — 이미 반증한 것

1. "postgres 가 죽었다" → **DB 는 멀쩡**했다. 트랜잭션 풀러만 고갈.
2. "users 테이블만 잠겼다" → **거짓**. 근거로 쓴 빠른 엔드포인트가 **전부 `Depends(get_db)`
   없는 정적 응답**이었다(대조군이 대조군이 아니었다).
3. "known_hosts 에 있으니 과거 접속 이력" → 호스트키는 **인증 전**에 등록된다. 증명이 안 된다.
4. "5초 주기 flush 태스크에 dispose 를 넣으면 하루 17,280회 풀 폐기" → **반증**.
   `flush_batch` 가 빈 큐에서 `if not rows: return 0` 으로 **세션 전에** 빠진다.
5. "dispose 가 동시 태스크를 깨뜨린다" → **반증**. 워커는 `--concurrency=5` **prefork**.
6. "app/tasks 밖에 누수 경로가 남았다" → **반증**. 밖은 **수동 스크립트 3개**뿐이고
   arq 는 **지속 루프**라 이 결함 클래스가 아니다.
