# 사통맵 — 4대 페르소나 관점 요구 발굴 (공인중개사·디벨로퍼·시공사·설계사)

작성 2026-07-30 · 근거: 코드 실측(레이어 인벤토리 vs 서비스 인벤토리) + jootek 벤치마크

## 0. 전체를 관통하는 발견

**지도에는 "현황 데이터"만 있고, 플랫폼이 이미 가진 "분석 결과"는 지도 밖에 있다.**

코드 실측:
| 축 | 플랫폼 보유 | 지도 레이어 |
|---|---|---|
| 접도·진입로 | `access/access_basis_service.py` | **참조 0건** |
| 일조·인동간격 | `site_score/solar_envelope·solar_placement` | **참조 0건** |
| 사업성(수지) | `feasibility/aggregation_engine·ai_optimizer·budget_execution` | **참조 0건** |
| 적산 | `cost/basic_building_cost·alternatives_engine·backtest` | **참조 0건** |
| 등기·소유 | `registry/*`(28) | **참조 0건** |

현재 12개 레이어는 전부 "무엇이 있는가"(지적·용도·공시·노후·실거래·분양·경매·POI·개발계획·지형·로드뷰)이고,
**"그래서 지을 수 있는가·얼마인가·누구 것인가"는 지도에 없다.** 개발여력 하나만 예외적으로 분석 결과다.

→ 페르소나가 원하는 것 대부분은 **신규 개발이 아니라 기존 분석의 지도 표면화**다.

## 1. 공인중개사 — "이 땅, 팔 수 있는 물건인가"

### 지도에서 더 얻고자 할 것
1. **소유 구조 한눈에** — 단독/공유(지분), 공유자 수, 법인/개인, 국공유 여부
   → 지분이 쪼개져 있으면 매수 난이도가 급증. *보유: 등기 갑구 소유지분현황(이번 세션 복구)*
2. **권리 부담** — 근저당 채권최고액, 압류·가압류, 지상권
   → 실질 매도가 산정의 핵심. *보유: 을구 근저당 3건 수신 확인*
3. **거래 이력** — 이 필지가 언제 얼마에 거래됐나 *(현재 "무자료" — 필지축 부재)*
4. **인접 필지 소유자 동일 여부** — 합필·일괄매각 가능성
5. **접도** — 맹지 여부는 매물 가치의 분기점. *보유하나 지도 미표시*

### 화면 아이디어
- 필지 색상 모드에 **"소유 구조"** 추가: 단독=진한색 / 공유2~5=중간 / 공유6+=경고색 / 국공유=회색
- 필지 클릭 시 **권리 요약 배지**: `근저당 3건 · 채권최고액 X억 · 압류 없음`
- **맹지 뱃지** — 접도 폭 0이면 필지 테두리 점선+경고

### 열린 질문
- Q1. 소유자 실명 노출 범위는? (등기는 마스킹 `남**` 상태 — 중개사에겐 충분한가, 더 필요한가)
- Q2. 인접 필지 소유자 대조는 개인정보 이슈가 있나? 합필 판단에 실무상 필수인가
- Q3. 중개사는 "매물 등록"까지 원하나, 아니면 "조사 도구"로 충분한가

## 2. 디벨로퍼 — "얼마 벌리나, 언제 막히나"

### 지도에서 더 얻고자 할 것
1. **사업성 즉답** — 이 필지에 지었을 때 대략 수익/NPV. *보유: `feasibility` 전체 · 지도 미표시*
2. **인허가 리스크 지도** — 개발행위허가 가능 여부, 협의 기관 수
   → 우리 강점(군사·보호구역 SSOT)인데 지금은 텍스트 목록
3. **실효 용적률 vs 법정** — 이미 있는 핵심 자산인데 지도 색으로는 개발여력 하나뿐
4. **경쟁 공급** — 반경 내 분양·인허가 예정 물량 (내 사업의 경쟁자)
5. **토지 매입 총액 시뮬** — 다필지 합산 시 실시간 매입비

### 화면 아이디어
- **"사업성 히트맵"** 모드: 필지를 수익률 구간 색으로. 개발여력 색상 문법을 그대로 확장
- **리스크 스택 바** — 필지 클릭 시 `군사협의·경사도·맹지·문화재` 를 막대로 쌓아 보여줌(무엇이 발목인지 즉시)
- 다필지 선택 시 **합산 카드 상시 노출**(면적·매입비·예상 연면적) — 지금 OUTPUT DOCK 안에 숨어 있음

### 열린 질문
- Q4. 지도에서 보고 싶은 사업성 지표 1개만 고르면? (수익률 / NPV / 총사업비 / 분양가능 연면적)
- Q5. 히트맵 기준은 "동일 용도 가정"인가, "필지별 최적 용도"인가 — 후자는 계산량이 크다
- Q6. 경쟁 공급은 반경 몇 km가 실무 감각인가

## 3. 시공사 — "지을 수 있나, 얼마 드나"

### 지도에서 더 얻고자 할 것
1. **진입로·도로 폭** — 장비 진입 가능성. 25톤 덤프·크레인 진입은 사업 성패
   *보유: `access_basis_service` · 지도 미표시*
2. **경사도·절토량** — 토공사비의 지배 변수. *보유: `terrain_service`(SRTM 30m)*
3. **개략 공사비** — ㎡당 단가 × 예상 연면적. *보유: `cost/basic_building_cost`*
4. **인접 건축물·이격** — 가설·안전 계획, 민원 리스크
5. **레미콘·자재 조달 거리** — 원가 직결

### 화면 아이디어
- **접도 레이어**: 필지 접한 도로를 폭별 색상(4m 미만 빨강 / 4~8 노랑 / 8+ 초록) + 맹지 X 표시
- **경사도 음영**: 지형도 레이어에 경사 구간 색을 얹음(현재 지형도는 배경만)
- 필지 클릭 시 **"시공 난이도" 3지표**: 진입·경사·인접 → 상/중/하

### 열린 질문
- Q7. 진입로 판단에 필요한 최소 정보는? (폭 / 포장 여부 / 회전 반경 / 종단 경사)
- Q8. 경사도는 평균으로 충분한가, 최대·구간분포가 필요한가 (SRTM 30m 해상도 한계 있음 — 정직 고지 필요)
- Q9. 레미콘 조달 거리는 실제로 의사결정에 쓰이나, 아니면 착공 후 문제인가

## 4. 설계사 — "무엇을 어떻게 앉히나"

### 지도에서 더 얻고자 할 것
1. **정북 일조 사선** — 북측 인접지 관계. *보유: `solar_envelope_service`(건축법 §86)*
2. **인동간격 기반 배치 가능 동수** — *보유: `solar_placement_service`(0.8H·판상/탑상/중정 3안)*
3. **실효 건폐율** — 법정이 아니라 통경축·조경·공개공지 반영 후 실제 앉힐 수 있는 면적
   *(이번 세션에서 사용자가 지적한 바로 그 갭 — 배치엔진은 "판상형 28% 밀도 손실"을 이미 계산 중)*
4. **대지 형상·방위** — 부정형·남북 폭·향
5. **높이 제한 중첩** — 고도지구 + 일조 + 비행안전의 최소값

### 화면 아이디어
- **일조 사선 오버레이**: 필지 위에 북측 이격 필요 거리를 반투명 밴드로
- **배치 미리보기**: 3개 대안(판상/탑상/중정)을 지도 위에 매스로 겹쳐 토글
- **높이 상한 통합 배지**: `min(고도지구 20m, 일조 18m, 비행 30m) = 18m` — 무엇이 지배 제약인지

### 열린 질문
- Q10. 지도 위 매스 미리보기는 2D 풋프린트로 충분한가, 3D가 필요한가
- Q11. 실효 건폐율을 "숫자 1개"로 줄 때 가정(용도·주차방식)을 어디까지 사용자가 고르게 할까
- Q12. 설계사는 사통맵에서 끝내나, CAD로 내보내 이어가나 (후자면 내보내기 포맷이 관건)

## 5. 공통 화면 구성 아이디어

### 5-1. **역할 프리셋** (가장 임팩트 클 후보)
12개 레이어를 매번 고르는 대신 역할별 기본 조합을 제공.
```
중개사   지적 · 소유구조 · 실거래 · 접도
디벨로퍼 개발여력 · 용도지역 · 규제 · 분양경쟁
시공사   접도 · 경사도 · 지형 · 인접건축물
설계사   일조 · 지적 · 고도지구 · 방위
```
→ 신규 데이터 0. **기존 레이어 조합 프리셋**이라 즉시 구현 가능.

### 5-2. 필지 색상 = "질문에 대한 답"
현재 색상 모드는 공시지가·노후도·개발여력 3종. 여기에 소유구조·사업성·시공난이도를 더하면
**같은 지도가 4개 직업에게 4개 답을 준다.**

### 5-3. "지배 제약" 한 줄
모든 페르소나가 결국 묻는 건 "무엇이 발목인가". 필지 클릭 시 최상단에:
```
지배 제약: 군사 통제보호구역(협의 필수) → 그다음 경사도 18%
```

## 7. 정직 경계

- 위 아이디어의 **대부분은 기존 분석의 표면화**지 신규 기능이 아니다 — 그래서 실현 가능성이 높다.
- 단, **경사도(SRTM 30m)** 는 해상도 한계가 있어 "참고" 이상으로 쓰면 안 되고,
  **레미콘 조달거리·인접 건축물 이격**은 현재 데이터 미보유(신규 조사 필요).
- **소유자 정보**는 개인정보 경계가 있어 노출 범위를 사용자가 정해야 한다(내가 정할 사안 아님).
