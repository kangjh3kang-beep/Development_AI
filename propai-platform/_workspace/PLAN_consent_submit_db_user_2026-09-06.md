## 2. 변경과 회귀가 아닌 근거

`CurrentUser` 로 받고 DB `User` 를 직접 읽는다 · 기본값 없이 필드 접근.

**회귀 아닌 근거**: 종전 코드는 **어떤 입력에도 무동작**이었다(항상 멱등 분기).
즉 이 변경이 깨뜨릴 "동작하던 것" 이 없다. 25 passed · ruff 통과.

## 3. ★검증하지 못한 것

- **라이브에서 동의가 실제로 기록되는지** — 이 수정이 **아직 배포 전**이다.
  배포 후 소급을 다시 적용하고 **동의 → 행 3건 → 플래그 false → 200** 왕복을 태워야 확증된다.
- 다른 엔드포인트에도 같은 `Depends(get_current_user)` 오해가 있는지 — **미측정**(형제 스윕 필요).
