## 3. ★검증하지 못한 것

1. **엔드포인트의 라이브 200 미확인** — 배포 전이다. SQL 은 프로덕션 스키마에 직접 태웠으나(P10) HTTP 통로는 아직이다.
2. **프로덕션 `search_path` 미측정** — `to_regclass` 를 무자격으로 바꾼 근거는 *"DDL 도 무자격이라 같은 규칙을 따른다"* 는 **추론**이다.
3. **꼬리 실행 이력이 1회분만** 남는다(`scan_state` 는 `last_scanned_at` 하나) — *"지난 4주 중 몇 번 돌았나"* 는 **말할 수 없다**.
4. **정정률의 기대값 미측정** — `해제 2.6%/월` 은 **다른 모집단**(노출별 해제율)에서 잰 값이라 대입하면 안 된다. 그래서 *"정정이 너무 적다"* 류 판정은 **넣지 않았다**.
5. **MOLIT 일일 한도 실수치**(P8) · **대상 증가율**(P7) — 둘 다 미측정.
6. **프론트 표면 없음** — 이 PR 은 **API 통로까지**다.
7. **`STALE_*` 임계의 근거는 크론 주기**이지 장애 통계가 아니다. 2주 중단이 `정상` 으로 읽히지 않도록 상한(14일)을 걸었으나 **그 상한의 근거도 추론**이다.
