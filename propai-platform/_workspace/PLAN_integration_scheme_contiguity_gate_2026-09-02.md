## 3. 변경 내용과 **회귀가 아닌 근거**

### ① `INTEGRATION_SCHEMES` 단일 집합 → **축 3분할**
- `AREA_DESIGNATION`(**「불가」 금지** → 조건부): 지구단위·도시개발·재개발·역세권활성화·역세권장기전세·
  도심복합·소규모재개발·주거환경개선·도시혁신구역·대지조성
- `REQUIRES_GARO_GUYEOK`: 가로주택 (축 = 도시계획**시설**도로 **4m 초과 관통**)
- `REQUIRES_HOUSING_COMPLEX`: 재건축·대지조성 (축 = **20m/8m/철도**)
- **회귀 아님**: P3 의 「면적 미달」 경로는 **이 게이트를 타지 않는다**(가드 `applicable != "불가"`).
  판정어는 저장소 자기 기준선 *"관할 확인이 필요합니다"*(`special_parcel.py:1670`)를 따른다.

### ② 결합건축 — **게이트에서 제거** + 조문 5곳 정정

## 4. ★검증하지 못한 것

- **모아주택·모아타운**: 법제처 **자치법규 조회 0건** → 근거 미확보. **게이트에서 빼지 않는다**(보류).
- `_buildable_types` 의 **상업·공업·녹지 분기**: 미측정. 이번 범위 밖.
- 역세권활성화 / 장기전세 / 주거환경개선의 **인접 요건**: 조례 근거 **미확인**(승계 문서도 미확인).
  → `AREA_DESIGNATION` 에 넣되 **「조건부 + 관할 확인」** 이라 과잉주장이 아니다.
- **§4(6m 단일상수 → 4m/20m/8m 실축)** · **§8(형상 미확보 양방향)** · **§9(세 번째 주소 붕괴)**:
  승계 문서의 처방 ④⑥⑦ — **이번 PR 범위 밖**. 보드에 좌표로 남긴다.
- 라이브 재현은 **제1종+제2종 1모집단**. 승계 문서의 **A/B/C 3모집단**은 이번에 재측정하지 않았다.
