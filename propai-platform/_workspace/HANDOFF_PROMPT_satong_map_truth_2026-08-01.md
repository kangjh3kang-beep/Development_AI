## 3. 다음 웨이브 (우선순위 순)

**W2 — 지오코딩 근원(최대 데이터 손실 계층)**
`_geocode_one`에 재시도·백오프가 없고 일시 실패를 5분 캐시한다. 같은 파일 계열의
`VWorldService._get`에는 **이미 재시도·지수백오프·지터가 있다** — 거기에 위임하라.
VWorld `response.status`/`error.text`를 읽어 `NOT_FOUND`만 미스 캐시하고 429/5xx는 캐시 금지.
`geocode_error_count`/`geocode_notfound_count` 분리 노출.
★그룹 키에 법정동이 없어(`key = name or jibun or dong`) 시군구 전역이 한 그룹으로 병합된다.
★마스킹 지번(`4**`)을 지오코딩하면 VWorld가 **리 중심점**을 준다(실측 1.5km 오차) → 좌표 강등.

**W3 — 자가진단 정직화 + 화면 예산**
자가진단이 실패한 요청이 아니라 **하드코딩된 다른 레이어·서울 고정 bbox**를 찔러보고
"정상"이라 답한 뒤 "줌·영역을 확인하세요"로 책임을 전가한다. `tileerror`의 `e.tile.src`를
그대로 재요청하면 동형 프로브가 된다. 배지 9종 → 단일 레지스트리 + 렌더 슬롯 상수 2개 +
도크 `max-h`(레일에는 이미 있는 패턴). `role="status"`/`aria-live`가 **0건**이다.

**W4 — 반경 정책 SSOT + 적응형 반경**
실측 최근접 실거래가 **1.35km**라 1km는 0건을 보장한다. 반경·기간 리터럴이 5개 서피스에
흩어져 서로 다르다. 통과 그룹이 임계 미만이면 단계 확장하되 **"반경 1km 무자료 → 5km로 확장
표시"** 처럼 **표기된 확장**이어야 한다(임의 확장 금지).

**W5 — 프로덕션 도달성 + 상태 영속**
`apps/web/app/api/**` 전 라우트가 프로덕션에서 **404**다(`/api/*`는 FastAPI 소유).
그래서 **AVM 항공 썸네일은 한 번도 뜬 적이 없다**. 배포 스모크에 "Next 라우트 도달성" 추가.
레이어 상태가 비영속이라 새로고침마다 다시 켜야 한다.

## 4. 이 캠페인에서 얻은 규율(반드시 지켜라)

1. **화면이 "무자료"라 해도 데이터가 없는 게 아닐 수 있다.** 백엔드 응답을 직접 확인하라.
2. **가설보다 실측.** "농촌 주소가 지오코딩에 실패한다"는 그럴듯한 가설이 **정반대**로 반증됐다
   (호미곶 8.7% vs 강남 42.4%).
3. **회귀락이 동어반복이면 아무것도 안 잠긴다.** 테스트가 값을 손으로 채우고 함수가 그걸
   존중하는지만 보면, **생산 코드가 그 값을 잘못 채우는** 회귀를 못 잡는다.
4. **이름이 곧 계약이다.** 필드명이 잘못된 멘탈모델을 인코딩하면 배선이 자연히 틀린 곳으로 간다.
5. **소스 불변식도 적대검증하라.** 이번에 같은 불변식이 3차 교정을 거쳤다.
   검사는 **교체가 아니라 병기**하고, 위치를 잠글 땐 **양쪽으로 결박**하라(상한만으론 샌다).
6. **"생존" 보고 전 주입 유효성을 확인하라.** 그 확인이 변이의 무효만이 아니라
   **불변식 자신의 약점**을 드러낸다.
7. **미처리는 "잠갔다"고 말하지 말고 커밋 본문에 그대로 밝혀라.**
8. 게이트는 변이 배터리와 **분리 격리 실행**. 주입 행수는 `diff | grep -c '^[<>]'`
   (`^<`만 세면 추가된 줄을 놓쳐 0이 나온다).

## 5. 작업 방식

각 웨이브마다: 실측 → 구현 → 3층 변이(로직·**배선**·표면) → 게이트 → **독립 적대검증
(code-reviewer 서브에이전트, 자기승인 금지)** → 봉합 → 머지 → sw 범프 → 통합자 배포 요청.

한국어로 보고하고, 무목업·라이브검증·완결게이트 원칙을 지켜라.
계획을 제시하기 전에는 `/insight-loop`으로 스스로 반증부터 하라.
