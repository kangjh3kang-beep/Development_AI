## 2. 변경 내용과 회귀가 아닌 근거

1. `cost_tables_bootstrap`: additive nullable 컬럼 + **`_ALL_DDL` 등록**(등록 안 하면 컬럼이 안 생겨 INSERT 가 터진다).
2. `cost_estimate_repository`: INSERT·SELECT 에 출처를 더하고 읽기 인덱스를 이동.

**회귀가 아닌 근거**: nullable 이라 기존 행 무영향. 옛 행은 복원 시 `None` — **모르는 것을 지어내지 않는다**.
반환 dict 에 키가 하나 느는 것은 additive 이며, 프론트 소비처가 0건이라 화면 영향 없음.

## 3. ★검증하지 못한 것

- **실 DB 왕복 미측정.** 이 테스트들은 SQL 계약을 **정적 파생**으로 검증한다.
  운영 DB 에서 `ADD COLUMN IF NOT EXISTS` 가 실제 적용되는지는 **배포 후 확인 대상**이다.
- 이 값이 **화면에 그려지는 날**의 표기(배지 문구·위치)는 이 PR 범위가 아니다.
- `market_unit_price` 를 화면에 안 그리는 것이 **의도인지 미완성인지 미측정** — 그래서 그리도록
  바꾸지 않았다(모르는 것을 제품 결정으로 만들지 않는다).

## 4. 되돌리기 경로

단일 revert. 컬럼은 nullable 로 남아도 무해하다(읽는 쪽이 없어지면 그냥 안 쓰인다).
